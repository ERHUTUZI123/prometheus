# Branch A checkpoint — independent constructive phase

This is a persistence checkpoint, not the v0 freeze. No other branch or old Prometheus candidate has been read. Model route is the inherited user-authorized gpt-6.1-sol, Ultra as reported in task instructions; no Pro claim and no independent API metadata probe.

QUESTION: Can a network acquire a new *scope of mutable computation* from interference feedback, while sharing the operation code, rather than requiring a programmer to preallocate independent state slots?
GIVEN: Local source PDFs; executable state updates and task errors are permitted. No evolution or open-endedness claim is needed. The proposed field below is an architectural hypothesis, not a source result.
NON-GOALS: General intelligence; universal novelty; learning already coded arithmetic; interpreting stable concentrations as acquired algorithms; a large training experiment.
VERIFIER: Exact source reconstruction; a finite analytic interference model with numerical checks; then an adversarial equivalence/cost check. This does not verify end-to-end acquisition of an arbitrary program.
BUDGET: Two concrete constructive proposals at most; one lightweight probe per central calculation; no networked or costly experiment; writes only A directories.
STOP: Freeze a coherent explicit mechanism with an actual worked calculation, including failure conditions; or record why no coherent candidate remains.

SOURCE: Artificial Chemistries (Banzhaf and Yamamoto, 2015), PDF 63–67 / printed 46–50: an object's bit string folds into its own operator and acts on another string. All reactants survive and a new executable string is born. Folding, thresholding, decay and the zero-string exclusion are designed. Thus code-as-data and constructive closure are already explicit precedent, not a new idea.

VERIFIED source convention conflict: PDF 65 / printed 48, eqs. (3.4)–(3.5), defines a nonnegative binary matrix dot product, subtracts Θ, and σ(z)=1 for z≥0. The prose gives Θ=0 as the Boolean case and calls zero a self-copying destructor. Literally Θ=0 maps every input pair to the all-ones string. The page image matrix-p48.png was inspected; this is not a missing PDF square root or OCR sign. Any Θ>0 or strict-step repair must be labelled ours.

SOURCE: Artificial Chemistries PDF 334–335 / printed 317–318 distinguishes a higher-level symbol y for an attractor basin from a species with reproductive strength. A stable pattern is not automatically a new causally autonomous executable entity. PDF 329–333 / printed 312–316 describes Jain–Krishna dynamics with negative selection and random rewiring, not task-directed neural construction.

SOURCE: Kauffman, Origins of Order, PDF 387–400 / printed 371–384: strings acting on strings, bounded families of machines/input bundles, and exact distinction between possible productions and their kinetics. Especially PDF 391–392 / printed 375–376: grouping five string transformations into an ordered machine changes effective timescales and collision probabilities. PDF 397–399 / printed 381–383: inhibition can change which potential productions actually occur; grammar operators may be carried by strings and ordered aggregates can self-assemble. These are close precedent, not acquired neural-program demonstrations.

SOURCE: von Neumann / Burks, Theory of Self-Reproducing Automata excerpt, PDF 21–25 / printed 83–87: constructor A consumes a description to build X, copier B duplicates the description, controller C alternates and attaches; mutations in optional byproduct D can be inherited while damaging A/B/C commonly prevents reproduction. The fixed constructor does not by itself discover useful D.

HYPOTHESIS currently being made concrete: treat the identity of a mutable computational instance as a learnable reaction affinity. Learned low-permeability scopes would make one acquired transition reusable with independent state, instead of copying its weights or allowing destructive state mixing. A constructive event adds state-bearing material; the error gradient changes affinity between material. A second possible proposal is exact trace assembly into reusable transition operators, but the sources already give most of its broad logic; it is not being represented as original.

OPEN: At exact symmetry a radial affinity has zero splitting gradient. A real birth/fission or noise event is needed. Context features must be observable; history already erased by pooling cannot be recovered merely by splitting. Differentiable addressing is close prior art; the strongest defensible distinction needs to be located in *learned identity/boundary and persistent state construction*, not in renaming attention as chemistry.
