## The phase benchmark computes a modular affine map

The actual BF residual is `e=(y1,y2-y1,y3-y2,y4-y3)`; see probes/BF/probe.py:26 and :32. All offsets are zero. Its 64 varied starts alter only the transient initial conditions: every query asks for the same all-zero solution modulo 2pi. The late-force learner sees this one fixed four-state difference operator, then learns four mobility coefficients. It is not evaluating 64 new functions, discovering a relation dictionary, allocating contexts, or learning how to map a new observed problem into the error coordinates. The proposed equivalence to nonzero acquired relational queries is algebraically sound but is not an end-to-end executed B-to-BF acquisition pipeline.

For B's actual learned rows, the forward operation is

`z=x+y-r+delta_A (mod 2pi)`;

the second relation gives `v=z+w-r+delta_B`, hence

`v=x+y+w-2r+delta_A+delta_B (mod 2pi)`.

Releasing x instead computes `x=z-y+r-delta_A`. In phasor coordinates these are products and inverses; in binary phases they can encode parity. The representation, multiplication/addition algebra, candidate grammar, and clamp roles are supplied. The selected relation and its offset really are acquired from examples within that grammar. A fixed prior does not negate learning, but these are the precise boundaries of the learned operation.

### Concrete stronger competitor

A generic stored-row interpreter repeatedly finds a relation containing one unresolved unit-coefficient port, subtracts its known terms from the learned offset, and assigns the missing phase modulo 2pi. It receives no answer or true planted offset. This uses the same causal algebra B already supplies for row cancellation. On a rooted unit-difference tree it is linear-time substitution; on cyclic, inconsistent, nonunit or underdetermined systems the frozen interpreter explicitly refuses rather than claiming a general solver.

The newly executed probes/final-attack/direct_substitution.py:13 implements that rule independently of author solvers. Actual B offsets `.4285029867333292` and `-.3044024539579113` were read from the existing results. Across 64 fresh forward, 64 inverse and 64 composition queries, maximum stored-relation residual and algebraic-output discrepancy were <=1.78e-15. Forward/inverse need three scalar additions/subtractions and one modulo; composition needs six and two. These counts omit row lookup, coefficient inspection, dispatch, storage and memory traffic. No sine evaluation or mobility training is needed.

For BF the same interpreter solved the unique zero target once, using four row scans, four additions/subtractions and four modulos; its independence from the initial free phases analytically covers the 64 recorded starts. The JSON's `correct_queries=64` is this coverage statement, not 64 distinct new target equations or 64 timed interpreter calls. No interpreter wall-clock superiority was measured.

**ATTACK:** A reduced number of force evaluations versus identity mobility on this family does not establish an advantage for constructing executable mechanisms over direct interpretation of the already acquired relations. The present software result supplies neither. This objection does not imply an impossibility of analog computation.
