## Exact question and mechanism

Can observed examples create a persistent executable relation, can such relations compose by sharing a dynamical state, and can the network generate a new internal interaction that accelerates that composition?

A stored relation has integer row `c`, complex observation trace `q`, learned phase offset `delta=arg q`, and strength `K`. All rows have zero coefficient sum, so computation does not depend on a global phase origin. Samples update `q <- q+(exp(i c theta)-q)/N`. Inference freezes that memory and releases selected ports under

`theta_dot = - C^T diag(K) sin(C theta-delta)`.

For `c=(1,-1,-1,1)` in roles `(reference,x,y,z)`, the relation computes `z=x+y-reference+delta` modulo `2pi`; freeing `x` instead executes the inverse relation. The same four-body term, not a separate readout, performs both operations. Phase multiplication and binary parity are examples of what this fixed primitive algebra can express.

Two separately learned factors `(r,x,y,z)` and `(r,z,w,v)` physically compose through the shared free phase `z`. Adding their integer rows cancels `z` and creates a five-port shortcut. This is a specified generic growth rule applied to learned factors. It does not constitute discovery of unrestricted physical primitives.

## The central countermodel, fully explicit

Consider four parent relations in deviations from any compatible desired solution. Let `y_0=0`, free phases `y_1,...,y_4`, parent residuals `e_i=y_i-y_{i-1}`, and add the logically entailed shortcut `s=sum_i e_i=y_4`. All offsets are correct. Equal positive strengths give

`E(y)=-sum_(i=1)^4 cos(y_i-y_(i-1)) - cos(y_4)`.

Set `alpha=2pi/5` and `y_i=i alpha`. Every parent residual is `alpha`, while the shortcut residual is `4alpha=2pi-alpha`. For each interior phase, adjacent sine forces cancel. At the last phase, `sin(alpha)+sin(4alpha)=0`. The gradient is exactly zero.

All five edge cosines are `cos(alpha)>0`. The Hessian in the free coordinates is

`H=cos(alpha) tridiag(-1,2,-1)`

with eigenvalues

`lambda_k=cos(2pi/5)[2-2 cos(kpi/5)]`, `k=1,...,4`.

They are approximately `[0.118034,0.427051,0.809017,1.118034]`, all positive. Therefore the winding state is a strict stable local minimum. Yet the output differs from the correct output by `|wrap(8pi/5)|=2pi/5≈1.256637` rad. Every parent relation is violated too; vector-field force cancellation hides all those errors.

The actual ODE was initialized at this winding state plus `[0.02,-0.01,0.015,-0.005]`. At horizon 60 it returned within 4.38e-6 rad of the wrong state, with output error 1.256634 rad. A small residual near a solution is not the only failure mode: the stable equilibrium itself carries the wrong computation.

This is the smallest member of this equal-strength chain-plus-one-shortcut family having `cos(2pi/(L+1))>0`; that restricted statement is not a claim of global minimality over all architectures. Uniformly scaling all strengths preserves this false attractor, so merely rescaling to a matched budget does not remove the counterexample.

**Consequence:** Constraint-level implication preserves the set of perfectly satisfying states, but adding the corresponding periodic potentials need not preserve the set of stable states of the physical solver. The mechanism compiler must preserve solver dynamics, not just logical entailment. This distinction is a meaningful candidate gap connecting dynamic organization to reusable neural computation.

## Scaffolding and closest rival explanation

Manually supplied: phase-valued carrier coordinates, a reference carrier, observed-versus-inference flags, local correlation grammar, nonlinear multiplication/conjugation primitive, port clamping, and the general row-cancellation operation. The finite example supplies port identities. The initial global grammar would cost `O(n^4)`; growing shortcuts can increase polynomial degree and coefficient size.

Learned/executed: which initial relation survives the observation statistic, its offset, its persistent parameter record, forward/inverse dynamics, simultaneous composition, and the algebraically generated shortcut row. A generic scalable co-use selector and autonomous cost/basin-aware acceptance process are not established.

Strongest rival explanation: ordinary Fourier relation estimation, higher-order energy-based constraint satisfaction and symbolic elimination already explain the construction. Existing oscillator equilibrium propagation already handles supervised XOR and multistability; adaptive higher-order phase networks already exist. No novelty or breakthrough is claimed. A close comparison to vector-symbolic binding/resonator systems and high-order associative memory remains necessary before promoting the architecture.

## Weakest link, failed branch, next single decision

The broadest fragile premise is that useful computational coordinates/relations can be discovered without encoding the desired mechanism in the supplied grammar and role allocation. The decisive failure found here is narrower: naive entailed-shortcut consolidation is not globally safe, even when every parent relation is exactly correct.

Failed branch: interpreting shortcut stiffness or the 30.9% local rate gain under a coefficient proxy as evidence of autonomous computational improvement. Preserve the positive two-factor result and the stable-winding failure together.

Next single decision: whether a dynamically faithful consolidation rule is scientifically promising enough to repair, while retaining a concrete plan to confront coordinate discovery and closest prior work. This branch has stopped after its finite construction/probe objective. No repair experiment is authorized by this certificate itself.
