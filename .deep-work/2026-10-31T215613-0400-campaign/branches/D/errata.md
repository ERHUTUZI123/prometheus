1. The schematic doubling example `aabccc -> aaaabbbbbb` is wrong. Correct doubling of all input character multiplicities is `aabccc -> aaaabbcccccc`. The original erroneous sentence remains in v0.md, whose frozen hash is unchanged. The probe protocol used the corrected target before execution. A separate direct raw-character doubling oracle checked the correction; results.json preserves both strings under frozen_v0_typo. Do not cite the original string as a successful worked run.
2. V0 treats PutPut as a universal edit obligation. Primary-source comparison showed this is unnecessarily strong for general lenses; some useful map constructions fail it. Revised requirement: GetPut and PutGet on the promised domain, and PutPut only for interfaces that explicitly promise overwrite behavior. The probe's lossless decoder satisfies PutPut structurally, which does not establish general lens behavior.

The total 2,194 output checks are post-selection checks, not all distinct held-out outputs. No result or criteria were changed to erase this distinction.
