SOURCE: §1.4 distinguishes nonlinear neural encoding, weighted linear decoding, and dynamics on represented state. §6.3.1 realizes multiplication without stipulating a single neuron that multiplies: an intermediate neural population encodes the joint operand vector m=(x,y). A decoder is selected for f(m)=m_1 m_2. On printed158 the explicit reconstruction is fhat(m)=sum_l d_l(m) phi_l^f, minimizing E_f=E_m[(f(m)-fhat(m))^2]; outgoing weights combine the receiving encoder with this decoder. Printed159 describes the demonstrated network as implementing a desired nonlinear function, not autonomously inventing which function to acquire.

RECONSTRUCTION: write feature responses over sampled operands as A∈R^{n×p}, desired output vector y, decoder w. Least-squares compilation gives w=A^+ y (with the stated sample/domain restriction). If A=UΣVᵀ then fitted output is U Uᵀ y on nonzero singular directions. Its representable functions and noise-sensitive dimensions depend on the neural response basis. For isotropic feature noise with variance σ², output noise variance is σ²||w||²; exploiting tiny singular directions can require large weights and amplify noise. This is an ordinary linear algebra reconstruction of the mechanism, not a new theorem or a universal biological claim.

SOURCE: §7.3 printed196–201 performs SVD to characterize which functions can be extracted from a fixed population. Broad approximately linear tuning supports an approximately polynomial basis, with high-order components weaker and more noise sensitive. Noise and the represented domain qualify the claim.

Consequence for candidate review: distributed activity can genuinely implement an operation without a named neuron or anatomical module. But choosing the desired f externally and compiling decoder weights does not itself explain learning to discover internal operations. Conversely, an architecture need not increase universal expressivity to change the finite-cost accessibility of an operation: changing feature geometry/conditioning can matter. The campaign must distinguish (i) implementing a supplied operation, (ii) selecting an operation from task feedback, and (iii) learning a construction process that changes which future operations are accessible.

This source does not supply an automatic constructor of representations, operator identities, or a general account of autonomous mechanism improvement. It blocks both the claim that all operation implementations require explicit symbolic modules and the claim that compiling one known nonlinear map is a new mechanism.
