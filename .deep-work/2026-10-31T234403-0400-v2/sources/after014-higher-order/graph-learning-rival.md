## Original 1 — Developmental Graph Cellular Automata

**SOURCE.** Waldegrave, Stepney and Trefzer (ALIFE 2023), [published PDF](https://eprints.whiterose.ac.uk/id/eprint/203478/1/isal_a_00658.pdf), actual PDF pp.4–8 (the repository cover is PDF p.1), model/experiment sections. Read the transition construction and experimental protocol, not only abstract.

State comprises directed adjacency A and one-hot node-state matrix S. The supplied local observation is incoming/outgoing Laplacian filtering:

    F_in=(D_in-A^T)S; F_out=(D_out-A)S;
    O=[F_in,F_out,1]W.                    Eq7–10,15,17

Each node chooses argmax among S+2 actions: change to a discrete state, delete, or duplicate. Duplication copies its entire incoming/outgoing connectivity; the duplicate receives another selected state. Thus a shared parameterized local law changes states and graph size/connectivity, using fixed duplication/deletion semantics rather than arbitrary emitted port graphs.

Crucially, actual evaluation samples random W, with 1,000 trials per state count, an eight-node ring seed, and 256-node/step cutoffs. It characterizes growth/attractors; computational fitness learning/evolution is future work. There are no computational I/O labels, terminal rewards, learned binding roles or evaluator acquisition. Unread: code and its runtime implementation. Treat the paper as developmental representation precedent, not an already-trained terminal-I/O rival.

## Original 2 — Self-Organising Digital Circuits

**SOURCE.** Barylli, Béna, Mordvintsev, Nisioti and Risi (ALIFE 2026), [arXiv v2 original HTML](https://arxiv.org/html/2608.02606v2), “Approach,” “Model,” “Training,” and “Toward Self-Organising Computational Substrates,” Eq1–5. Also read the [author methods page](https://self-organising-circuits.github.io/). PDF fetch exceeded web-tool size; HTML is the directly read primary body. Use v2's method description rather than silently mixing its implementation details with the author page.

Each gate stores LUT logits, hidden memory, depth encoding and optional feedback. A shared one-hop topology-masked Transformer emits residual updates to LUT logits and memory (Eq1–4). Gates are arranged in a supplied feed-forward DAG with **fixed wires**; changing LUTs changes functions and effective routing, not the physical graph.

The update rule is trained by differentiable LUT execution, task BCE and BPTT (horizon five). The circuit executes every tick; the random-wiring regime supplies per-output mean absolute task residuals (Eq5), propagated through local communication. Initialization includes noisy pass-through LUTs. No intermediate target gate configurations are required, but this is richer within-rollout feedback than one terminal reward. Training must charge task-batch circuit executions and backpropagation, not only policy hops. V2 describes padded-neighborhood attention. Add/prune/rewire remains explicitly future work. Unread: code, raw records, complete numerical validation and exact hardware costs.

These distinctions support constructing a clear learning rule; they do not show that it is original or better. “Learned local functional organization” is already covered at a meaningful mechanistic level. “Mutable graph with a neural local rule” is also prior art even when its inspected evidence is not computational learning. The unestablished conjunction is the specific one the current raw-stream machine must actually acquire.

A faithful comparator must remain faithful. Adding a sampled port-matching head, atom-reference transport, and rule-role installation to either paper would create a new proposed method, not reveal an existing implementation of K. Equally, dismissing the raw-stream machine because these neural systems could simulate it would establish nothing about learning or resource costs. Existing Neural GPU and NRAM comparators remain the concrete conventional acquisition tests already documented; these two works sharpen the mechanism boundary rather than replace those comparators.

A promising claimed difference would require an actual result in which terminal extensional evidence constructs persistent syntax/binding/copy/execution interfaces through the shared local law, with all formation costs charged. A hand-designed evaluator demonstrates expressibility only. Merely replacing fixed wires by a larger graph-generation vocabulary does not yet supply a formation principle, and combining two known ingredients is not automatically a new principle.
