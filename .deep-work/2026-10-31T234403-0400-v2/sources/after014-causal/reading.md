## Checked originals

**SOURCE — Asiaee (2026), Efficient Discovery of Approximate Causal Abstractions via Neural Mechanism Sparsification.** https://arxiv.org/html/2602.24266v1 . Read §§1–3.4 directly; child also read §§4,6–7. Mechanism replacement keeps a unit, sets it to a constant, or replaces it by an affine function of retained units; projection forgets replaced units, and retained-variable interventions map to the same low-level units. Compiling replacements yields an executable reduced network. There is no supplied semantic high-level SCM requirement. Interchange verification tests teacher fidelity, while discovery uses a task-loss approximation. **RECONSTRUCTION:** this defeats the broad novelty claim that no-high-level-model self-intervention can create executable organization. It does not by itself establish acquiring new reusable operators from failed trajectories for later tasks.

**SOURCE — Tomaszewski (2026), Can Neural Networks Learn by Experimenting on Themselves? Self-Interventional Learning from Functional Consequences to Predictive Self-Knowledge.** https://arxiv.org/html/2608.14894v1 . Directly read introduction, §§2.4–3.7 and §§4.1–4.3. Learns g_phi(I) predicting functional discrepancy c(I), then chooses structural actions by predicted consequence. Synthetic self-discovery uses unlabeled probe inputs; labels can enter initial supervised task training, while subsequent self-intervention/repair uses unlabeled buffers. The paper distinguishes learned response prediction from a full SCM. **RECONSTRUCTION:** predictive self-knowledge and structural use are prior targets; this candidate instead uses task-labelled patched runs to fit a new donor-free computation. That is a proposed different training target, not proof of novelty or benefit.

## Exact information gap

An internal patch yields a neural output, not its correctness. Teacher consistency certifies teacher behavior only. A valid raw-input recombination rule would supply extra structure. Current proposal instead sends the actual patched rollout's answer to the same original-task evaluator; it never asks the evaluator to label a hidden state or an invented counterfactual input. The cost is active terminal evaluations and potentially severe combinatorial search. Consistency and reusable-module learning remain open rather than being supplied by a causal oracle.
