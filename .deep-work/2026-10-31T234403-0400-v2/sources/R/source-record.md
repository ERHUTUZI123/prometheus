## SOURCE — Dana Angluin, 1987

*Learning Regular Sets from Queries and Counterexamples*, Information and Computation 75, 87–106. DOI: 10.1016/0890-5401(87)90052-6.

Original paper read at <https://homepages.math.uic.edu/~lreyzin/papers/angluin87.pdf>. Substantive passages: pp. 88–89 on teacher assumptions; pp. 90–93, §2.1 and Theorem 1/Lemmas 2–4; pp. 93–95, §2.2, Fig. 1 and state-count argument. The checked source claim is limited to those passages.

**Load-bearing reconstruction:** rows record outcomes after suffix experiments. Closure ensures every one-action successor has a represented row; consistency ensures equal rows have equal successors. Consequently transition `row(s) --a--> row(sa)` is well defined. Distinct rows need distinct states because some suffix gives different answers. A failed consistency check adds a distinguishing suffix, splitting an old equivalence class; failed closure adds a new represented state. Exact learning requires membership and equivalence/counterexample help. This is a direct precedent for witness-driven representation growth, so that feature alone cannot be claimed here. The candidate's hypothesized additional step is to learn finite relations generating structured families of states.

## SOURCE — Yoshihiko Futamura, 1999 revised original

*Partial Evaluation of Computation Process—An Approach to a Compiler-Compiler*, Higher-Order and Symbolic Computation 12, 381–391; updated/revised version of the 1971 paper.

Substantive text read at <https://static.aminer.org/pdf/PDF/001/006/665/partial_evaluation_of_computation_process_an_approach_to_a_compiler.pdf>: §2 pp. 382–383, equations (1)–(3) pp. 383–384, α1 operations (2)–(5) pp. 385–386, nontermination discussion pp. 386–388, append example p. 389.

**Reconstruction:** specialize π on supplied constants c while leaving r residual, obtaining α(π,c)(r)=π(c,r). Applied to an interpreter this yields an object computation; self-application yields the compiler relation. The graph algorithm preserves dynamic branches and memoizes a branch with its static environment, reconnecting repeated configurations. A changing static environment can still generate an infinite residual graph. Thus turning execution context into code is an old mechanism, and termination cannot be assumed. This source motivated rejection of an insufficiently distinct “neural partial evaluator” as the primary candidate.

The 1971 English scan was downloaded from the author's site to `futamura-1971-original-english.pdf`. Web extraction returned no text; screenshot results did not expose images through this tool wrapper; system pdftotext and common PDF Python modules were absent. I therefore do NOT claim to have read that scan. The substantive reading above is the author's revised paper, with the distinction retained.

## SOURCE — Jürgen Schmidhuber, 1992

*Learning to Control Fast-Weight Memories: An Alternative to Dynamic Recurrent Networks*, Neural Computation 4(1), 131–139.

Author-hosted original HTML read at <https://people.idsia.ch/~juergen/fastweights/node2.html> (§2), <https://people.idsia.ch/~juergen/fastweights/node5.html> (§2 limitations) and <https://people.idsia.ch/~juergen/fastweights/node8.html> (§3.2).

Checked mechanism: a slow feedforward network produces differentiable changes to a second network's fast weights. The FROM/TO interface produces changes as products of activations; gradients propagate through the changing weights. The binding example explicitly stores a car location in temporary connection weights. This establishes that a learned controller writing another network's computational parameters is not a new proposal by itself. It does not establish learning the generative algebra proposed in R. The v0 mechanism does not rely on reproducing its reported experimental result.
