For a learned bilinear core

    mu_C(h,e(x))_k = sum_(i,j) C[k,i,j] h_i e_j(x),

define M_x[k,i]=sum_j C[k,i,j] e_j(x). Then the SAME executed state transition is h^+=M_x h, with the same coefficient tensor, state dimension and arithmetic. Learning C changes the transition tensor but does not escape a linear second-order recurrence merely by calling it a multiplication law. This is a precise representation correspondence, not a universal-simulation objection. A nonlinear final decoder or embeddings do not make all arbitrary models equivalent to finite weighted automata; the correspondence is only for this bilinear sequential core and the stated readout/input conditions.
