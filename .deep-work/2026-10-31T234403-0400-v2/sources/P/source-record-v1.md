# P v1 targeted primary reading

These readings check the actual nearest controls for the stronger construction. They do not constitute a complete novelty survey. No downloaded paper code was executed. Candidate hypotheses and derived examples are not source results.

## S7 — Lee et al., Difference Target Propagation, arXiv:1412.7525v5

Original technical HTML: https://arxiv.org/html/1412.7525

Read Sections 2.1–2.3, equations (8)–(15), Algorithm 1 and Theorem 2.2. Feedback maps are trained using layer-local reconstruction of noise-perturbed inputs. Difference targets use h_old + g(target_above) - g(h_above), and forward layers are trained toward local targets. Theorem 2.2 requires small target displacement, differentiability and a specified Jacobian contraction condition; it is not an unconditional discrete repair theorem. The method already acquires feedback computations that facilitate updating forward neural computations.

Boundary: P v1 cannot claim acquired backward credit assignment generally. The proposed extra content is intervention alternatives/costs, persistent shared edits, acquired library composition and changing repair interfaces. Whether those additions help must be tested against this actual neural method and ordinary autodiff.

## S8 — Polozov and Gulwani, FlashMeta, OOPSLA 2015

Original author-hosted PDF: https://alexpolozov.com/papers/oopsla2015-flashmeta.pdf

Read Section 5.2 Definitions 10–12; Section 5.3 and the dependent-parameter discussion. Witness functions map an output specification to necessary parameter specifications; precise witnesses add sufficiency, and conditional witnesses fix other parameters. The dependent Concat example shows why individually precise parameter specifications cannot simply be recombined. Conditional branching/skolemization handles these dependencies. The system explicitly counts on operator/domain witness knowledge while making the synthesis algorithm generic.

Boundary: inverse semantics, set-valued targets and dependency-aware composition are established. P's prospective difference must be how a growing neural computer acquires/compresses/refines repair procedures and uses them to change future acquisition, not the deductive algebra itself.

## S9 — Vijayakumar et al., Neural-Guided Deductive Search, ICLR 2018

Original Microsoft Research PDF: https://www.microsoft.com/en-us/research/uploads/prod/2018/01/main-ml2search.pdf

Read Search Strategy on PDF pp. 4–5 and Section 3.3. PROSE performs top-down decomposition using operator-specific witness functions. NGDS adds neural estimates of branch quality and a controller, retaining the symbolic deduction that structures satisfying programs. The branch-and-bound controller combines predicted branch scores with actual discovered program scores; neural learning does not replace the domain witness semantics in the documented method.

Boundary: this is an actual strong neural/symbolic control. Matching budgets should include primitive execution, learned guidance, acquisition and graph access. Newly learned repair interfaces should not be handed to it at zero cost, while its existing conditional deduction capabilities must not be omitted.

## S10 — Alford et al., Neural-guided, Bidirectional Program Search for Abstraction and Reasoning, arXiv:2110.11536v2

Original technical HTML: https://arxiv.org/html/2110.11536

Read Section 3.1's inverse/conditional-inverse construction and Section 4 Future Work. Forward partial execution and inverse evaluation create grounded values and ungrounded targets in a search graph. The paper's demonstrated abstraction and bidirectional-search approaches are distinct. Its future-work paragraph explicitly proposes combining them and synthesizing inverses/conditional inverses for new abstractions. Therefore the high-level plan to grow both a forward and inverse library was already articulated; a proposed integrated implementation alone is not established novelty.

Boundary: the specific intervention-cost, persistent-edit and interface-refinement coupling remains a candidate to assess, not something proved new by this reading. The linked MIT thesis PDF returned HTTP 429 and was not used as an additional source; the paper's own technical text suffices for this boundary.
