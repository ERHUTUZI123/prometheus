## SOURCE: Irie, Schlag, Csordás, Schmidhuber (ICML 2022)

Original: https://proceedings.mlr.press/v162/irie22b/irie22b.pdf . Local
srwm-2022.pdf; substantive PDF pages 2–3, §2–3 equations (1)–(8), and page13,
Appendix A equations (9)–(11). Pages3 and13 were also visually inspected.
The paper has18 PDF pages. Other experiment/results sections were not audited.
Hugging Face's paper CLI supplied a read-only Markdown mirror; acquisition is
not a claim of having read the complete mirror or PDF. No author code executed.

The fast-weight programmer has separate slow projections, an outer-product
delta update, and a context-dependent fast matrix. SRWM uses its own current
matrix to generate key, query, output and learning rate; its own key/query reads
supply target/current values. Only the initial matrix of this layer is trained
by outer gradient descent. The full implementation uses four distinct rates and
multiple heads, with additional surrounding network layers.

RECONSTRUCTION, restricted to the single-rate equation(8): with kbar=phi(k),
qbar=phi(q), eta=sigmoid(beta),

    W_next = W [I + eta (qbar-kbar) kbar^T].

Thus the full matrix's column space cannot escape its initial column space
under this simplified update, although nonlinear key/query generation changes
the realized time-dependent computation. This is a direct algebraic property,
not a universal limitation of self-modification or an experimental result.
Appendix A prevents extending it naively to the full matrix: different row
blocks have different right factors. Each block has its own column-space
containment, which can be vacuous for full-row-rank blocks. Surrounding layers,
nonlinearities, precision and dimension matter. In particular it is incorrect
to infer that the complete architecture cannot learn new functions from the
single-rate factorization.

What this changes: “weights write weights” and runtime changes to the updater
already have concrete neural precedents. A candidate must isolate a different
organizational consequence or acquisition process rather than count weight
changes as the new principle. Fixed shape is not itself a novelty veto.

## SOURCE: Behrouz et al., Nested Learning (2025 original v1)

Original https://arxiv.org/html/2512.24695v1 . Selected §8.1, equations(76)–(86)
and text through the specified DGD/weight-decay choice; introductory prose used
only as navigation. No benchmark, historical-priority or biological claim was
independently checked. Remaining sections/appendices unread here.

The section lets projection/update-related memories adapt in context; each
memory generates its own target values, while initial memories are meta-learned
in the outer loop. Its stated concrete design supplies the local regression
objective and an optimizer family. This is a substantive prior for recursive
adaptive memories, not evidence that all possible learning rules arise without
scaffolding or that a candidate's hoped-for capability has been demonstrated.

RECONSTRUCTION: an internal value target can be generated by the current
memory and still be shaped through outer task loss. The existence of an outer
objective neither defeats self-organization nor makes every such system
equivalent. Compare represented state, update algebra, feedback and persistence
separately. No experiment or new architecture was executed in this source check.
