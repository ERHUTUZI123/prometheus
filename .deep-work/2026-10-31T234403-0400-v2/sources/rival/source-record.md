## Sources substantively read

1. **Guttag, 1977. Abstract Data Types and the Development of Data Structures.** [Original paper scan](https://cecs.wright.edu/~tkprasad/courses/cs7100/guttag-cacm77.pdf), CACM20(6),396–404. Read §§2–4, printed397–400 / PDF2–5, including queue axioms, symbol-table refinement, stack/array equations and representation mapping. Defines an abstract type using operation syntax and relations; develops an implementation using other abstract types. R's possible increment must be acquisition/selection of these contracts and its later learning consequence. It is not the fact that relationships specify a resource. PDF/text saved.

2. **Phillips, 2021. A reconstruction theory of relational schema induction.** [Full primary text](https://pmc.ncbi.nlm.nih.gov/articles/PMC7864426/), DOI10.1371/journal.pcbi.1008641. Read Results' reconstruction and completion sections, Methods Theorem65/Definition70, and relevant discussion. Recovering a monoid from its representation category and applying free-M-set completion supplies an actual algebra→transfer precedent. The universal reconstruction statement is not a finite-observation learning guarantee. The examples share algebraic structure; it does not implement task-selected memory construction. Local HTML retrieval returned an access challenge, retained as `phillips-2021-retrieval-challenge.html`; substantive reading used the web full text, not that file.

3. **Claessen, Smallbone, Hughes, 2010. QuickSpec: Guessing Formal Specifications using Testing.** [Author-hosted original](https://smallbone.se/papers/quickspec.pdf), §2, PDF3–5. Read term-universe generation, test-based partition refinement, equation representative selection, congruence pruning and substitution limitation. It is a close direct rival to R v0 empirical equation induction. Functions/types/test-data generators are supplied; trust remains conditional on testing. The tool does not select and instantiate new internal semantics by task utility. PDF/text saved.

4. **Smallbone et al., 2017. Quick Specifications for the Busy Programmer.** [Author-hosted original](https://www.cse.chalmers.se/~jomoa/papers/quickspec-JFP.pdf), JFP27e18. Read web-extracted §3.2.1–3.2.2 and §3.4 opening/implementation, printed9–10,17–18: interleaved testing/pruning, term rather than equation enumeration, and term-rewriting pruning. This strengthens the simple rival: use tested laws to prune further law search rather than brute-force every relation independently. PDF saved; not a full paper read.

5. **van Heerdt et al., 2022. A Categorical Framework for Learning Generalised Tree Automata.** [arXiv primary](https://arxiv.org/pdf/2001.05786), §§2,5 termination,6, PDF3,12–16. Read fixed-varietor setup, automaton dynamics, contextual wrappers, supplied unordered-tree equations, finite-target termination condition, local closure/consistency and finite counterexamples. Its learner infers algebra dynamics over a specified F/free-algebra construction; equations determining the quotient input structure are part of the instantiation. This is narrower than learning the operational presentation itself. Its termination hypotheses cannot be transplanted to R's expandable potentially infinite action graph. PDF/text saved.

6. **Sargsyan, 2026. Functorial Neural Architectures from Higher Inductive Types.** [arXiv primary HTML](https://arxiv.org/html/2603.16123v1), §§2–3, Construction3.2, Theorem3.3 and Remarks3.4–3.5. Read how supplied HIT generators, composition and relation cells map to networks, concatenation and homotopies. The checked boundary is supplied algebraic specification→architecture; it does not infer the presentation by task feedback. No endorsement of the paper's broad attention impossibility claims or empirical effect sizes: those were not independently validated. HTML saved.

7. **Cai, Guo, Williams. Holographic Algorithms Beyond Matchgates.** [Author preprint](https://homepages.inf.ed.ac.uk/hguo/papers/HA-general.pdf), §§1–2,4 opening; PDF2–3,5–6,10. Read transformability definitions, affine/product class structure, orbit interpretation, and explicit affine-support/quadratic-phase membership algorithm. Theorems1.1–1.2 supply polynomial known-class recognition/search controls. Their scope is not every arbitrary local-gauge tensor compiler. Read existing current-run source PDF read-only; extracted text saved under rival.

8. **Mocherla, Lao, Browne. Extending matchgate simulation methods to universal quantum circuits.** [Primary arXiv](https://arxiv.org/pdf/2302.02654), §§1.5–4, especially PDF5–8,10–11. Read sparse Pauli representation, total Pauli rank cost, Majorana conjugation between graded spans, ZZ departures and fixed/variable departure-count bounds. Explicit Gaussian core plus non-Gaussian residual simulation is established. Its PI-SO quantum-circuit assumptions and rank-based simulator differ from K's general planar tensor boundary conditioning. It supplies a rival mechanism, not proof that K's exact bound or task-learning claim is covered. PDF/text saved.

9. **Mele, Herasymenko. Efficient learning of quantum states prepared with few fermionic non-Gaussian gates.** [Primary full text](https://arxiv.org/html/2402.18665), main I.2–I.3 and supplement III.1 Theorems26–27 with proof. Read constructive orthogonal compression of the span of conjugated Majorana directions; Algorithm1 estimates correlation matrix, extracts Gaussian frame, then does tomography on small residual subsystem. The Gaussian/unitary/copy-access conditions matter. This is especially close to K's learned frame/hard-residual localization; it does not demonstrate K's cumulative semantic acquisition. HTML saved.

10. **Liao et al., 2019. Differentiable Programming Tensor Networks.** [Primary arXiv](https://arxiv.org/pdf/1903.09650), §IIA–B, PDF2–3. Read chain-rule computation graph, local vector-Jacobian primitives, custom differentiable primitives and exact versus approximate contraction distinction. This establishes ordinary AD as the appropriate boundary for K's derivative insertion repair. It does not imply that differentiating a pointwise-only replacement gives ambient derivatives. PDF/text saved.
