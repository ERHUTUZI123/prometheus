## 2. A：学习路径等价关系，随后改变允许的学习空间

**实际状态与执行。** 有限图的每条边存储 \(U_e\in SO(d)\)，反向边用逆矩阵。输入路径逐段执行

\[
h_{k+1}=U_{e_k}h_k,\qquad P_\gamma=U_{e_L}\cdots U_{e_1}.
\]

输入编码器和端点解码器共享，不能直接读取路径标签。任务端点误差经 \(\delta_{k-1}=U_k^\top\delta_k\) 反传；更新为普通 Lie 群梯度，未称为无需全局反馈的局部学习。

**第一版获取规则。** 为每个局部面学习一个身份关系位 \(r_f\)：

\[
L=L_{task}+\sum_f\{\mu r_f\|C_f-I\|_F^2+\lambda(1-r_f)\}.
\]

RECONSTRUCTION：消去独立的关系位，恰好得到 \(L_{task}+\sum_f\min(\mu\|C_f-I\|_F^2,\lambda)\)。同信息的普通正交循环模型用这个正则项即可执行同样的规则；该位没有改变执行或参数共享。

**认真发展的修复。** 接受关系后，用 \(U=\Phi_R(\xi)\) 将它编入参数化。若一条关系为 \(Q U_e S=H\)，消去 \(U_e=Q^{-1}HS^{-1}\)，并替换所有共享出现，不能逐个面独立修补。未解的残余约束、循环依赖和过长表达式被显式拒绝。推导了完整路径微分、可行梯度投影、规范方向以及有限补偿更新：

\[
A'=e^{\eta\Xi}A,\qquad B'=Be^{-\eta\Xi},\qquad B'A'=BA.
\]

它确实能保护声明的完整算子，但没有从这个恒等式产生新的获取规则。若 A 只是开放路径的一段，它还不是可与根闭路直接比较的操作；需要新增可访问闭路或固定读出接口，并计入成本。

**已完成的承重推导。** 固定连通图、固定根坐标，选择生成树后可把全部树边规范为 I；每条非树边就是一个基本闭路的完整算子。若这些完整生成算子都受保护，所有闭路行为就都固定，剩余自由只是规范变化。该具体边界不排除部分保护、图增长、非线性或耗散机制。监督提出结构，根协调器展开并核对了证明；不冒称两份独立发现。

**最强对手及判断。** Path Development Network 已有可学习乘性 Lie 群执行；MatrixNet 的已给关系惩罚不等于自动获得未知关系；Network Morphism 覆盖简单保功能分解。修复的现有结构选择规则，是给定候选关系后拟合、验证与计费；同信息的精确方程学习器可逐步执行它。未知关系获取仍是 OPEN，没有因找到一个先例而声称整个方向已解决。

## 3. B：历史区别可能需要不同种类的记忆

**初始构造。** 从实际付费的路径及拼接反馈拟合双线性余项，形成中央扩张：

\[
(g,z)*(h,w)=(g+h,z+w+g^TCh).
\]

当 \(C_{12}=1/2,C_{21}=-1/2\) 时，得到逐段有向面积累加器。完整手工轨迹和结合律已展开。但它精确对应四状态线性递推；一般有限维结合代数的右乘法也给出同维矩阵执行。该例没有表示资源优势。

**改变表示族的修复。** Chen 原著引出一个更有内容的限制：在特征零、有限过滤、**同伦不变的幂零／幺幂迭代积分记忆**中，\(\mathbb Z/2\) 的区别会消失。令 \(u=g-1\)，则 \(u^2=-2u\)，有限增广商不能保留非平凡元素。

这不是完整路径签名、任意 CDE、非线性读出或任意神经网络的不可能性。不能省掉这些限制。

修复在给定 good cover 上学习边位 \(t_{ij}\in\mathbb F_2\)，满足三角形约束，执行

\[
s\leftarrow s+t_{ij}\pmod 2.
\]

全局闭路标签可选择非平凡覆盖：SO(3) 的一次完整旋转与两次完整旋转，在四元数提升中分别到达 −1 与 +1。这里确实需要离散层状态，而不是继续提高实数幂零阶数。

**未填的获取步骤。** good cover、纤维类别和足够的全局查询仍然给定；同信息的常规覆盖推断／四元数跟踪复现规则。因此没有为了展示奇偶性再运行实验。新的认识是一个受限表示边界，不是新学习原则。

## 4. 不把可逆性当必要条件：耗散关系候选及实际检查

这是对另一个基础假设的独立评价，未把普通能量模型重命名为拓扑，也未宣布替换 MAIN。

**状态、执行与学习。** 残差网络表示关系 \(r_k(z;\theta_k)\)，钳制已观察变量，空闲状态执行

\[
E_\theta(z)=\tfrac12\sum_k\rho_kr_k(z)^2,
\qquad z^{t+1}=\operatorname{clip}[z^t-h\nabla_zE_\theta(z^t)].
\]

参数由有限 T 步的任务输出损失更新。若学得紧凑关系，它可能在不同钳制、逆向查询和组合下复用；但“能量相加”和“通过展开下降训练关系”已有 COMET／IREM 的具体规则。根协调器亲自进入了原文方法与训练方程，没有只采纳摘要。

**获取修复。** 实际拒绝的完成值触发最小不可扩展部分赋值的寻找，再创建 no-good 因子、用 Boolean 多项式压缩。没有免费扩展 oracle：通过完整有效性查询枚举补全，最坏可指数级。该规则获取观察变量上的约束，并未获得紧凑隐含算法；同信息符号约束获取可执行同一过程。

### 一个预先推导、随后实际执行的有限反例

双方获得同样四个正确关系 \(ab=bc=ca=abc=1\)，唯一解为 (+++)。候选的允许实例是

\[
E=\tfrac12[(ab-1)^2+(bc-1)^2+(ca-1)^2]+.05(abc-1)^2.
\]

在 \(a=b=c=t\) 上，驻点方程是

\[
t[2(t^2-1)+.1t(t^3-1)]=0.
\]

执行前证明了 \((-1,-.9)\) 中存在严格错误极小点；Hessian 横向特征值大于 .8，纵向大于 2.86、全部小于 4.7，所以步长 .1 的离散执行也有一个错误吸引域。证据不仅是浮点特征值为正。

| 预先固定的检查 | 实际结果 |
|---|---|
| 四个因子分别钳制完成 | 全部正确；269/269/269/2589 次更新 |
| 对称／非对称负初态组合执行 | 49/275 次更新后均到错误极小点 |
| 错误驻点 | \(t\approx-.9543604146575684\)，\(E\approx.18663593455\) |
| Hessian 特征值 | 约 (.8216076,.8216076,4.0704767) |
| 正初态／零初态 | 前者正确；后者停在鞍点，仅为次要控制 |
| 同关系 GF(2) 消元 | 秩3，唯一 (+++)；6 次宽4行异或 |

这否定该执行器的无条件组合可靠性；没有测试因子学习，也不否定所有权重、初态策略、随机执行或能量算法。候选本来就承认可能有坏极小点，不能将它整套假说写成被此例完全证伪。

**执行边界。** 一次现有隔离 runner 进程，外部60秒上限，exit0；内部 .01447575 秒，工具所报 .293053125 秒。390条原始记录，6项冻结 hash 不变。记录了377次推断向量梯度、3400次单因子标量梯度评估代理；含诊断共392次能量、389次向量梯度、6次 Hessian 调用。不是完整 FLOPs、物理能耗或一般效率比较。无训练、安装、结果调参或重复运行。

**认真修复，而非只留否定。** 改用完整联合分布：

\[
p_{t+1}(s)\propto p_t(s)e^{-\eta E(s)}.
\]

满支撑和正能量间隙使错误联合状态权重指数衰减，确实修复该连续陷阱。但完整状态需 \(2^n\) 个权重，MAP 成为显式枚举；这里 GF(2) 对手更直接。该修复有推导，未执行；没有伪称新的紧凑推理机制。

**旧证据比对做晚了。** 旧 campaign 的 B 证书已经证明相容周期约束制造严格错误吸引子，BF 已处理 SPD 修复的边界。新符号实例和离散对手不同，科学失败类型相同。它只算开发诊断，不作为新颖性或 MAIN 推进的凭据。不能用另一个例子延长这条线。
