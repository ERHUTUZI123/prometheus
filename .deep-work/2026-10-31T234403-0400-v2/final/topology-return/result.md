## 实际新增的计算与学习规则

一条统一的研究问题贯穿以下构造：共享实现可以改变，但其旧操作语义及实际执行质量要分别受到保护，全部形成/维护/执行成本都要进入比较。

**第一步：把“保护”与“能继续学什么”写成具体模型。** P构造锚点固定的可逆神经耦合，证明同一参数可学习非零连续输出，而全部旧根回路端点不变；同时给出具体的冻结核心+端点适配器强对照，揭示其可能更低的执行成本。这个版本不作为成本优势，不运行立方关系演示。[完整构造](../../candidates/topology-return/construct-p.md)

K构造共享拓扑泵控制图，推出固定力幅下一个原本失败的短截止时间，在解析参数更新后可满足，而旧操作及所有旧词保持。它明确给出实际状态域、读出、有限时间吸引管、无重置组合与新能力后续保持约束。更新是手工解析推导，没有冒称训练实测。[完整构造](../../candidates/topology-return/construct-k.md)

**第二步：用强对照定位并实质修订。** 时钟重排的精确前沿说明：若输入时钟自由，那个一参数几何改变可以由编译时序重现；人为加入时钟限制不能制造胜利。这个结果限定该版本的成本解释，没有关闭拓扑方向。[前沿推导](../../candidates/topology-return/retiming-frontier.md)

继而改变真实执行规则，使共享参数改变二维流的方向：

    x_dot = -M_theta(x,u) grad_x(|P(x,u)|²/2) + noise,
    m I <= M_theta <= Mmax I.

保持旧根覆盖的同时，正定神经 mobility 可以改变实际轨迹，不能一般地编译成标量时钟。根协调器与P推出统一残差管：

    D⁺|P| <= -m s² |P| + B + S nu,
    (B+S nu)/(m s²) < r0 < root-neighborhood boundary margin.

在已付费获得的局部、分离、初始状态及导数界条件下，任意允许的共享参数更新都保持旧分支执行。没有假定正定矩阵乘积欧氏正，也没有声称能从任意初始化逃出错误极小点。

P进一步证明了同一实际速度上限下，相对**最佳标量重定时**的有限方向收益及真实任务梯度；普通矩阵预条件/已知根反馈仍能匹配。K给出了另一套完整快操作及**付费恢复回旧接口**的过程，同时明确标出标量 M=I 在该例中更强。两项结果都不被包装成总代价胜利。[根规则与证明](../../candidates/topology-return/mobility-root.md) · [独立推导/代价边界](../../candidates/topology-return/mobility-audit-p.md) · [完整操作与恢复](../../candidates/topology-return/mobility-repair-k.md)

**第三步：真正进入量子拓扑的共享学习实现。** 根协调器直接进入非阿贝尔编织原著，构造共享神经相位/能隙控制器，采用明确的 Y-junction 边路径及有限时间校正 Hamiltonian。独立核查纠正了编码资源：固定总宇称下，单独四个活跃 Majorana 的基态空间不是非平凡量子位；加入两个 spectator 并计入路由/耦合/制备后，给出六模逻辑码。没有把一般有能隙的 Berry 回路都叫拓扑保护。

在这个明确模型中，共享权重可持续改变执行形状，而理想旧 braid 保持。实际执行还需要校准与控制误差界。已推导：

    A = integral ||H_cd||dt = 3pi/4,
    C_cd = integral ||H_cd||²dt >= A²/T,
    T >= A/hmax.

所以更快不能自动叫总代价更低。控制校正、幅值/slew、旁观模式、初始化、读出、闲置态保护与校准都要付费；数字仿真不能声称物理量子能耗优势。[具体量子规则、推导与编码修复](../../candidates/topology-return/quantum-shared-control.md)

**第四步：把校准信息从免费假设变成可观察、可计价的学习。** 对一个明确而受限的共同正增益模型，推出逻辑态制备—演化—二元量子测量协议，非直接读取增益：

    Pr(X+ | kappa,h,tau) = cos²(kappa h tau),
    n >= A² log(2/delta)/(kappa_L² epsilon_gate² h² tau²).

这个固定时间充分 shot 上界计入制备、演化、读出和先验/去混叠条件。没有假定已获得任何 shot 或缩小不确定区间。未知非线性响应、SPAM、漂移、额外 Hamiltonian 项、不同通道增益仍需各自的信息与验证。同样的信息给直接鲁棒控制方法。

更一般的响应包络给出条件性保持评分 `A e0+L C_cd+rT` 及其学习准入规则；这是充分验证器，不是实际门错误下界。新获得的短截止时间必须进入未来旧能力合同，不能只保护抽象逻辑类。按当前最坏词误差界，固定容差下充分 shot 数还会随最大词长平方增长；这不是所有校准或量子纠错策略的普遍下界。[观测与查询成本推导](../../candidates/topology-return/calibration-observation.md)
