## 实际计算机制

**RECONSTRUCTION / 已执行：** 初始关系为 P=z³-u，已有操作 A 是三个旧状态的循环。系统拥有设计好的生长工具

    Q_epsilon(z,u)=(z-3)(z³-u)-epsilon.

执行状态包含实际保留的复数分支 z、控制 u、共享系数 epsilon、随参数迁移的语义锚点、已测操作表及其实际路径。复数用两个实坐标计算。路径预测与 Newton 校正实现约束延拓；理想连续规则包含控制和系数两项：

    dz = [(z-3) du + d epsilon] / Q_z,
    Q_z=4z³-9z²-u.

系统枚举自己关系的全部有限临界值，构造带完整往返柄的候选回路；这里没有给它成功的 B 路径或正确程序。实际运行四个明确准备的分支实例、观察端点、支付逆路径复位，形成操作知识。独立多项式根求解只检查数值跟踪，没有用于替换保留状态或给选择器提供正确分支。

## 完整例子与实际结果

**ACTUAL MEASUREMENT：** epsilon0 时第四状态虽被分配却不能参与操作。测得的群只有3个元素，3次任务查询均失败。随后系统迁移到预设非零提案 .1，通用编译器枚举全部4条临界回路，测得候选作用；选择 L2 作为 C。

    A: [0,1,2,3] -> [1,2,0,3]
    C: [0,1,2,3] -> [3,1,2,0]

发布的 A、C 及逆操作生成24种置换。环境仅返回四个实际输入实例的标量奖励；5次查询找到程序 A→C：

    [0,1,2,3] -> [1,2,3,0].

成功路径与这个程序均未作为教师答案交给选择器。这里的“接受生长”仍是设计好的有限结构搜索，不是任意拓扑的创造。

获得 C 后，系统在 A/C 实际轨迹节点优化连续实现目标：

    R=Q_u/Q_z,
    J=mean |R|²,
    dR/depsilon=-1/Q_z²-Q_u Q_zz/Q_z³,
    g=mean 2Re(conj(R) dR/depsilon),
    delta=-.0005 g/(1+|g|).

这是实系数方向、固定控制样本上的敏感度梯度；不是局部常数的离散置换奖励梯度。g=.0009974315385915132，与预先规定的有限差分相差1.92e-12。实际系数 .1→.09999950178116988，随后状态与锚点通过同一参数路径迁移，未重新设成求解出的根。

J 从 .03085056876591287 降至 .03085056826916764，相对下降约1.61e-8。这一极小变化只证明更新确实发生且与目标相符，不证明显著效率、最大条件数、任务能力或能耗改善。

更新后 A、已获得的 C 和任务程序保留语义。预先指定的4条组合都实际执行；其中 AC 恰好与学得任务程序重合，因此只有以下3条属于未用于任务选择的新组合：CA、ACA^-1C^-1、CAAC A^-1。它们的端点与已测库的组合预测一致，没有通过更多标签拟合。

## 保留依据与证明边界

**RECONSTRUCTION / 精确条件已执行检查：** 有限旧生成操作在同一个状态嵌入下保留，可逐字归纳推出所有旧组合保留。若旧群传递，再获得一个连接新旧状态的换位，则其共轭产生星形换位，生成更大的全置换群。这是标准群作用的重建，不是新数学成果。

获得 C 后的保留证书不是采样最小间隔。程序用精确有理数检查整个 epsilon∈[.0995,.1005]：四个互不相交的小圆盘通过严格 Rouché 不等式包围全部临界根；临界值的 Taylor 像界与 A/C 每段完整折线路径严格分离。4个根圆盘、8个整路径比较和3072个线段比较全部通过，记录中最大有理数分子／分母为506bits。

它证明规定数学家族的临界值在整个更新区间不穿过这些固定路径，从而在共同参数迁移下保留其置换及所有有限组合。它不证明浮点跟踪舍入误差、未测试噪声管或无限长度运行的可靠性。实际数值跟踪另以根残差、独立根匹配、逆路径和端点检查支持；最大观察根匹配误差约9.52e-13。

## 强常规对手与当前重要性判断

**具体算法对应：** 同一执行约束下，拥有同样源代码、系数、导数、准备权限和反馈的常规多项式／延拓规划器，就是当前实现的算法。没有独立重跑一个相同算法冒充第二种方法，也没有用“通用网络能模拟”否决它。当前步骤的作用可以完整地由这个已明确构造的常规对手解释。

只要求数字输出时，常规 FSM 直接使用同一批已支付的操作表。代码实际用16个有向表项、60次表查询完成任务程序和4条指定组合，输出一致。若要求操纵同一连续系统，表规划器仍须执行并支付物理路径；两种执行约束不能混为同一效率比较。

当前所有任务观察只读取 A/C 置换表；其闭包已经是 S4。证书允许的系数更新保持整个“词→置换”映射，因此在此接口里不能产生新的离散功能或降低后续任务获得成本。这是本接口的具体边界，不是拓扑或神经计算不可能有用的结论。

与 Fundamental Question 的联系是：一个内部可执行操作被获得、在共享实现改变时保留，并被复用到程序中。若能从经验获得有用的关系／构造策略，且在相当信息和资源下改变常规方法仍有的重要限制，才可能提升为更有意义的学习原理。当前尚无这样的已构造后继规则；单纯增加次数、回路或字数不会解决这个缺口。
