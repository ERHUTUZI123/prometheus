# Exploratory acquisition/transfer pilot v1 — frozen before execution

QUESTION: Can finite-effect prediction trained from external program outcomes guide the propagation of real function changes to new independently parameterized positions, and revise its predictions through paid history? Does its action differ from cheap curvature/replay or an equally informed contextual optimizer?

GIVEN: candidate-v1.md; review005; NumPy in the existing read-only numerical environment. Cells are tanh of four fixed input features. Each output program combines two cells as tanh(v_i+s*.7*v_j+.3*v_i*v_j). Teacher cells reuse latent ingredients plus independent perturbations; IDs/teacher parameters/local teacher outputs are withheld by the code's learner interface. This is a designed synthetic distribution, not a natural task or an enforced secret holdout.

BUDGET: one inspected Python process, externally capped at 120 seconds, three fixed seeds 3101/3102/3103, 36 training worlds times 24 events per seed, 4 new evaluation worlds times 30 events per seed, 10 cells/18 programs, 9 public probes. Q is a 48-hidden-unit tanh MLP fitted for 350 minibatch steps. No tuning/retry on outcomes. Amplitudes [-1,.5,2], four distillation steps, one fresh eight-example recipient audit/event. All candidate activations and scans charged. Same exogenous input/event streams but selected recipient labels can differ across adaptive policies. Every arm gets the same label count and native use of those labels, not identical adaptive realizations. Training audits uniform. Deployment 0.1 exploration; log actual propensity. All arms evaluated on the SAME untouched 128-point/program external evaluation stream; these evaluation targets never enter learning.

CONTROLS: local-only; random route; cached first-order; cached curvature; exact cached finite replay; learned Q. Contextual learned-optimizer action-value head using Q is an algebraically identical control. Record different work counts; no equal-compute or total efficiency claim from equal labels. No benchmark/architecture superiority claim. Pre-audit utility includes every chosen packet, even harmful ones. No rollback oracle. Native SGD on acquired audit labels follows all proposals.

STAGES: train Q from uniform finite audit episodes; freeze Q and transfer to new positions/graphs; halfway through evaluation change one hidden ingredient and allow new labels to revise history. Compare frozen-old versus current history predictions at the same current checkpoint after change. A no-history feature ablation checks whether the acquired predictor uses observable recipient evidence. No correct hidden routing labels.

VERIFIER: finite-difference check of source gradients and external first/second response derivatives; exact affine-consumer finite-effect identity; serialization smoke; recorded requested/realized packets; untouched full-program losses and unaffected-program retention; pre-audit prediction errors and harmful-route counts; native/generic-policy identity. These checks do not prove causal generalization beyond this generator or novel mechanism acquisition.

STOP: process failure/timeout/nonfinite values => preserve partial evidence; no silent rerun. After this constructive execution submit actual results to independent supervisor before more implementation. A failed predictor does not prove the general idea impossible; a successful predictor does not establish paradigm-level value.

OUTPUT: append-only raw.jsonl, summary.json, execution.log; immutable pre-execution code/config hashes. Main campaign continues or ends only on main-level scientific judgment, not because this probe ends.

PRE-EXECUTION AUDIT: P independently read the actual code; found no core derivative, future-label or common-stream bug. Cost counters are explicitly partial operation proxies: cell forwards, backpropagated example count, distillation steps and MLP forward matrix multiplies. Feature construction, Python overhead and MLP training are not a complete FLOP total. Predictor acquisition is separately fixed at 350 minibatches of 128 per seed. The contextual-optimizer control is a structural equivalence plus repeated-Q determinism check, not an independently trained second optimizer. No total-efficiency or superiority inference is licensed.
