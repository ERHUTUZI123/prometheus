## Gradients and actual projection

True task loss is mean half-squared terminal loss. RTRL uses `dA'=sech²*(r+A*dA)` and `dbeta'=sech²*(x+A*dbeta)`. Conditional write loss uses actual predecessor held fixed: its active logit derivative is `-y*(m-y*r)*sech²/N`. Carry uses the mean quarter-normalized separation hinge with derivative `-gap*sign(delta)/2` divided by192; predecessor states are fixed for its one-step derivative. Exact zero absolute-value difference uses subgradient0. No conditional term is labeled a full task gradient.

For the projected arm the code builds actual one-step **transition parameter Jacobian** rows on ORIGINAL zero-input holds, not error-scaled/loss Jacobians. It performs modified Gram-Schmidt with a second orthogonalization pass and absolute rank tolerance1e-12, then subtracts row-span components from the local write gradient. It does not assign a mask or manually freeze A. The scalar result should follow from the rows, but rank0 is recorded rather than replaced by the desired mask. Only write is projected; true task and conditional carry remain unprojected. The reported scalar sum of losses is expressly not a certificate that this combined vector is its true gradient.

Preflight finite differences at A1.05/beta.12/v.8 compare true task RTRL with replayed perturbations and conditional write/carry with one frozen predecessor bank on both +/- sides. One-step HOLD Jacobian checks use frozen predecessor states from first/last original holds. The projection preflight uses the actual acquired checkpoint, checks annihilation residual, and applies one **diagnostic, unretained** projected-write step to inspect hold preservation on those actual frozen predecessors. This is not an extra training update. It also records near-zero old-task loss alongside a nonzero model Jacobian so fit error does not erase the protected operation.

No assertion that these checks pass is made before execution. Any failed check aborts with prior rows retained. Full combined updates do not inherit the isolated component's exact hold-preservation claim.
