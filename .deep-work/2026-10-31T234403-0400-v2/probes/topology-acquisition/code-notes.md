# Pilot implementation notes — unexecuted

`pilot_v1.py` is a new single-process NumPy implementation. It does not import the previous check. Importing it performs no execution or writes. Root owns the execution contract, external runner, independent audit, and `certificate.py`.

The process carries four states and separately migrates four semantic anchors. It starts on the uncoupled degree-four relation, measures old A and every generic compiler loop, and tests every distinct measured group element by actual word execution plus inverse reset until scalar reward one or finite exhaustion. The uncoupled result is expected to fail. It then migrates to epsilon .1, explores every unique critical value without supplied B, selects the least-cost measured transposition moving the added state, publishes only A/C and inverses, and repeats the measured-group reward search. Other candidate paths are diagnostic only.

The compiler pays for one `np.roots` solve per epsilon and uses `u=4z^3-9z^2`, which remains defined at epsilon zero. Duplicate critical values are clustered at `1e-5*(1+max(abs(a),abs(b)))`. Each lollipop uses the nearest-to-home entry, 128 straight-handle segments each way, and 256 circle segments. Its model segment-distance check is numerical and does not claim an exact continuation certificate. All four branches are actually tracked. Root solves within the tracker's observer are independent verification only and never choose a state, branch, path, or task word.

The target four-cycle appears only inside `TaskEnvironment.reward`. Learner BFS depends only on measured permutations and receives only scalar feedback. Every task trial costs four actually executed cases, including the identity trial; all inverse paths/reset work are charged. BFS minimizes generator count, not geometric cost. C is separately selected by measured forward branch-steps, polyline length, then deterministic name. Structural acceptance explicitly compares uncoupled failure with coupled task success; the supplied growth grammar itself is not called learned.

BFS discovered/expanded graph states and examined transitions are counted. Every four-state table composition is charged four logical transition-table lookups. The explicit digital compiled-FSM rival evaluates the selected task word and held-out words using only the same already paid measured A/C tables; it records outputs, lookup count and sixteen stored directed permutation entries. The same-actuator conventional rival is exactly the owned-model compiler and search law already executed here: its acquisition information/work are shared, no duplicate run is presented as independence, and no algorithmic performance advantage is claimed.

J and its derivative use all four branch values at the same declared A/C polygon nodes, including the initial node. Adaptive substeps are charged but do not change this fixed sampling grid. For `R=Qu/Qz`, the derivative is `-1/Qz^2-Qu*Qzz/Qz^3`; the mean `2 Re(conj(R)*derivative)` produces exactly one real epsilon step. One central finite-difference check with h=1e-6 continues virtual copies of these exact trace branch points at the same controls by predictor/Newton correction, checks local branch identification, charges all model evaluations, and reports gradient agreement without a physical-reset claim. The frozen pass condition is `abs(g-gFD) <= 1e-4*max(1,abs(g),abs(gFD))`; failure aborts before the native update without tolerance/step retuning. This optimizes a conditioning surrogate, not the locally constant permutation reward. A/C are never regenerated after learning.

Before any native update, both actual binary floats epsilon and epsilon+delta are checked via `Fraction(float(...))` against `[199/2000,201/2000]`. Root's exact certificate receives all four critical-z centers from the already charged epsilon .1 solve and fixed A/C arrays. Certificate failure stops before migration and leaves the retention claim unverified. The certificate concerns no-crossing on fixed polygon paths over the uniform parameter interval; it does not certify floating-point tracking or noisy tubes. The process independently transports state and anchors through the accepted epsilon step and actually reexecutes A/C, the acquired word, and fixed held-out mixed words. J_after is observed and may fail to improve.

All normal raw records use JSON round-trip validation with `allow_nan=False`; the first serialization record precedes computational batches. Output files use exclusive creation. Deadline 110 seconds, 200000 global vector step calls, depth 12 and correction budget 12 are internal termination paths; root's external cap remains required. Costs separately expose four-branch work, critical solves, verification solves, F/J evaluations, corrections, subdivisions, preparations, migrations, task cases, failed paths, certificate wall time/comparisons and storage proxies. Exceptions preserve failure and last-valid-state records; the code does not tune or retry the entire experiment.
