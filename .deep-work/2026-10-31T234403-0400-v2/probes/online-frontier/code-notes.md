# Code returned for root inspection; not executed or frozen by worker

`pilot_v1.py` is a NumPy/manual-BPTT implementation. It contains the two nonlinear six-state producer blocks, exact A scalar Jacobian at every current return, full/one-dimensional/raw B caches, external-label-only adaptation, capped scout formation, held-out two-context nonlinear compositions, a formed-packet reassignment and required numerical/serialization checks.

Declared choices needing root contract review:

* Six scouts/context: four training and two validation. Full h/J working snapshots survive only the current scout episode. A separately counted **raw B input/current-u/observed-label replay archive** holds the four training episodes until the six-step adaptation-aware port fit; it contains no h/J snapshots and is then dropped. Finite-difference outer objectives recompute one episode at a time and charge the forwards/native updates. This is paid replay, not erased-information reconstruction.
* The gradient port uses the principal covariance direction of the full consumer's actually learned `w²c`, a known adjoint/model-reduction component. PCA uses actual B-state covariance. The adaptation-aware baseline starts from the same gradient initializer and takes six fixed outer finite-difference steps on the same four episodes. Its eight inner steps reuse an eight-example batch: **MAML-Rep-style**, not exact OML Algorithm 2.
* Validation first admits RETURN_U if it meets post-native-learning reference loss tolerance and lower complete cache bytes; otherwise tests the learned B port; otherwise falls back to raw replay. Full/raw and the cache-reader support N-dimensional native consumers; a narrow port has a scalar native feature coefficient. Differences in capacity/conditioning are reported, not called identical trajectories.
* Production has all six context pairs at both lengths 64/128. Both delays 8/64 are simulated from the same frozen numerical trace without rerunning its learning; waiting byte-time is computed explicitly and no sleep is used. The fixed reassignment permutes all four formed gradient packets/cuts. Across the complete pair set and each length, context multiplicities, code/port/cut marginals are identical.
* Native adaptation on held-out pairs uses only **whole composed-program labels**, with exact consumer derivatives for both children. Child target values are environment-local and are never passed to the learner. Query predictions are logged before query labels are revealed.
* The producer update is one actual partial-SGD step per controlled common-checkpoint trial, with adapted beta held fixed. Its result is used for an additional fresh eight-query composed-program evaluation, with predictions logged before labels. Thus production uses 8 support + 8 main query + 8 post-update query labels per arm, equally. It is not a hypergradient through beta adaptation, and trials do not claim stale online-gradient correctness. All producer numerical parameters remain eligible; formed p is meta-only/fixed within that production trial and has no hidden native `dp=hB` cache.
* Raw replay computes support B states once, query states/tapes once, then one BPTT VJP per query after external loss cotangents are available. Current A capability is explicitly emitted/logged before any B computation in all arms. A source parameter version is shared explicitly in the per-trial model arrays.
* `numeric_bytes` counts unique NumPy allocation sizes (view bases included), not Python objects, RSS, allocator overhead or energy. Waiting-cache/model/native-state counts cover the declared arrays. Return-copy overlap and all transient allocator work are **not completely instrumented**, so the production/probation peak fields are explicitly **incomplete/conservative working-state proxies**, not actual measured unique allocation peaks. Counts of core operations are proxies. Full environment arrays exist in the harness but are not learner cache reads; isolation is instruction-only.
* A bounded **cache-ridge** control is implemented: using the same paid raw scout archive, replay B after the gradient port is known, compute actual `(z,Jz)`, and fit `hB ~ standardized[z,Jz,1]` by fixed ridge. Sufficient statistics accumulate one episode at a time; full h/J datasets are not retained forever. All replay, one-VJP, fitting and decoder arrays are counted separately. Production consumers see only decoded features from their actual cache, and their producer update differentiates the z path while **STOP_GRAD_J** metadata columns remain constants. This is an explicitly surrogate producer rule, not an exact higher-order derivative. **Predeclared diagnostic override:** the decoder is deployed on the gradient method's formed scalar-port contexts even when its own decoder bytes fail the common scout byte-admission test. Its own validation/admission result and complete extra cost remain recorded; u-only contexts remain u, and the gradient method's raw fallbacks remain raw. It is a COSTED information diagnostic, not an admitted low-memory winner. Arbitrary cache inference and exact Hessian-through-metadata learning remain missing stronger controls, not presumed impossible.
* **Full-projected diagnostic:** use exactly the gradient method's accepted p and cut/raw-fallback choices, but retain actual full `hB` and `JB` whenever that method uses a scalar port. At use time compute `HB@p` and contract its producer gradient through `JB`; the scalar consumer, initialization, native SGD and data are unchanged. Compare predictions, adapted beta, complete producer partial gradients and fresh post-update loss to tolerance `1e-9`, without storing huge gradient arrays. Its larger cache/Jacobian work is charged. If no scalar port was formed, the record explicitly reports zero actual projected contexts; matching raw/u fallbacks is not called a substantive retirement test.
* **Fixed last-m input control:** `suffix_replay_m16` retains a real copied trailing 16-step B input buffer, resets B state to zero at that suffix, and otherwise uses the full N-feature consumer and the same native learning steps. It charges its actual input bytes, support/query replay and query BPTT. A predeclared initial-version Lipschitz check reports the full-vs-suffix state error and the bound `min(2 sqrt(N), ||W||_2^16 sqrt(N))`; production records fresh external prediction/loss gaps from complete raw replay without asserting they are small or tuning m. Producer partial gradients are exact for this explicitly truncated algorithm, not for the full history. Current A/u processing remains complete.
* **Hybrid suffix control:** `hybrid_suffix_m16` reuses the gradient method's same paid early-u cut; every non-u context uses the fixed suffix-replay control instead of a scalar port. It adds no fit/tuning and pays the same cut acquisition dependency. This separates a benefit of skipping B from an alleged benefit beyond strongly fading-memory replay.
* Formation records separate shared data/scout costs and method-specific finite-difference/decoder/validation work, with an explicit per-arm attribution map. Full-projected/reassignment/hybrid diagnostics pay the reused gradient formation; the cache reader additionally pays its ridge/validation work; fixed controls use no formation. The common scout proxy is conservative, not an optimal standalone acquisition implementation. Production shared-model accounting includes all four deployed context specifications, not only the two currently called. No per-method amortization claim should use the aggregate multi-method formation total as if it were one method's cost.
* Held-out context compositions reuse the same hidden teacher-direction family learned during scouting, with new sequences, task coefficients and lengths. They are not genuinely shifted learning demands, and v1 contains no demand-shift/reprobation revision experiment. This limits any claim beyond the tested distribution.

No test result, runtime measurement or freeze/hash claim is made here. Root owns inspection, contract, execution and interpretation.
