# Exploratory acquired physical-frontier pilot — working contract before code freeze

Same active V2 after review009. Sealed stage007 and the passed cover-growth probe remain unchanged. This contract is finalized/frozen with the inspected code before execution. No neural acquisition result or paradigm-level claim is presupposed.

## Scientific target and significance

QUESTION: Can actual finite later-consumer-learning evidence form a cheaper executable return/cache boundary of a neural producer, while current-output/current-gradient tests select an inadequate one? Does the acquired organization carry to new consumer compositions, input lengths and waits under complete cost accounting? Does an ordinary adaptation-aware representation/cut learner already reproduce it?

Success would be one intermediate acquired organization: a large transient neural workspace returns a learned small interface and required credit, so useful continuing learning need not keep that workspace live through all later events. Important broad prospect: constructing larger internal computations without proportionately enlarging lifetime credit memory. This finite family cannot establish that the constructor learns algorithmic abstractions generally or that its mechanism exceeds existing module/representation learning.

## Formation, controls and intervention

Fixed capped scout episodes give every formation method the same legitimately acquired support/query observations, full reference states and allowed gradients. Completed scout replay/meta-fitting costs count; open scouts are capped, expire/censor if feedback exceeds their budget, and production has no permanent full shadow. Actual constructor metadata/projections must be retained/charged after scout data are released.

The implemented scope is a supplied two-body program and a supplied cut grammar (return after A, after B through a scalar port, or retain/replay B), with paid paired finite native adaptation -> reject/revise -> formed later port -> held-out validation -> executable production return. It does not implement general support-ledger-directed region discovery or structural rewiring from v4. Existing future-gradient/model-reduction tools propose its features. Query loss after native learning and complete resource costs, not current agreement alone, decide admission.

Controls include current-only return; full-state/credit return; raw/hybrid replay using actual retained inputs and parameter version; state/PCA or current-gradient reduction; learning-continuation reduction; and a post-adaptation port learner with cut search. A minibatch-reuse inner loop is MAML-Rep-style rather than an exact OML Algorithm2 reproduction. Record the actual code's learning schedule. No published architecture benchmark is reproduced by naming this small control.

Formation-evidence reassignment permutes learned cut/projection records across procedure bindings while leaving production labels, native AD, total formation data, proposal/compute budget and interface access unchanged. It must not grant true teacher directions, free counterfactual labels or unavailable cache values. The intervention diagnoses acquired association of evidence with executable interfaces; it is not itself a novelty certificate.

The strongest same-information control can exploit raw inputs and all legally retained cache bits under identical execution rules. The pilot includes a bounded ridge reader of actual (z,Jz), fitted from paid scout replay; no hidden h/J is supplied in production. Its producer step differentiates the z column and uses STOP_GRAD_J for metadata, an explicit surrogate rather than an exact Hessian-through-metadata gradient. Deploy it as a costed diagnostic on the formed non-u ports: the original scout-length byte gate would reject every such decoder and make this purported control vacuous. Arbitrary optimal cache inference/mixed AD remains unimplemented. All gradient information that survives counts even if hidden from a standard consumer API.

The strongly contracting producer can make very long raw history unnecessary under the same approximate task-loss criterion. A fixed last-16-input reset/replay control is declared before outcomes, with the same full-feature native consumer and actual retained-input/compute charges. A port advantage only over full-stream exact replay would not establish an intrinsic long-history learning advantage. No truncation-length sweep is authorized by this contract.
