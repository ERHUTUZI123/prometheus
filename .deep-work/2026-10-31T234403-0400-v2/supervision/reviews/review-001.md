## The pivotal obstruction

An action must descend through the retained equivalence relation. If `C(q1)=C(q2)` but a new construction gives distinguishable future behavior, no deterministic operation using only `C(q)` can reproduce both. Calling this later refinement cannot recover information already deleted.

For the coordinator's concrete scalar example, `V=U^T=(1,0)` and `(3/5,-4/5)` both have `H=[[1,1],[1,1]]`. Their entire old factor-SGD behavior agrees at this interface. Replacing the hidden identity by coordinatewise ReLU gives outputs `1` and `9/25` at input `1`. I checked the two products directly. This refutes unrestricted source-neuron reactivation from H; it does not refute quotient-defined construction or partially retained exceptions.

The ambitious claim must therefore specify how the system acquires construction actions whose semantics are available from retained state, and how newly exposed learning state is maintained. Classical abstraction refinement is a relevant description of checking an interface. A potentially meaningful computational mechanism would also choose and execute a useful new operation, preserve its subsequent edit semantics, and manage the resulting resource tradeoff.

## One constructive next action

**AGENT PROPOSAL / RECONSTRUCTION, not yet executed:** promote a boundary-selected latent mode into an explicitly nonlinear trainable path while retaining a compact residual learning state. This tests a change in computational kind, rather than only a new preconditioner.

Let `d=d_out+d_in`, `H=ZZ^T`, and let a constructor choose `t in R^d` from available training context and retained state, with `t^T H t>0`. Define

```
s = Z^T t / sqrt(t^T H t)       (source lift, unit norm)
r = H t / sqrt(t^T H t) = Zs
H_res = H-r r^T
r = [v;u]
```

The source residual is `Z(I-ss^T)`. Since this is an orthogonal projection, its Gram is exactly `H_res`, which is PSD. Its forward block is `W_res=W-vu^T`. Before changing computation, the residual plus extracted path reproduces the original function and old simultaneous-SGD behavior: an orthogonal factor decomposition does not change Euclidean factor SGD.

Introduce the explicit path

```
f_new(x) = W_res x + v [u^T x + c phi(u^T x)],   c=0 at birth.
```

For a differentiable nonlinear `phi`, such as a bounded-domain square for an exact small test, insertion preserves every current output. Later gradient updates of `c,v,u` can create nonlinear behavior. The residual source still enters the loss only through `W_res`, so it retains its exact compact congruence law using the actual boundary gradient. Existing nonlinear exceptions remain explicit. This yields an executable retained state consisting of `H_res` plus the nonlinear path parameters.

Crucially, `r` is computable from H alone and is unchanged by any orthogonal change of source hidden coordinates. This construction has a well-defined lift across the whole old source fiber; it does not guess the deleted neuron orientation. A second promotion can use the *updated residual* and a newly selected t. Thus the source may have arbitrary redundant width while retained state depends on interface dimension and the number of deliberately exposed nonlinear modes.

Freeze one finite contract for this cycle: choose t by a declared task-feedback rule with counted proposal/evaluation work; promote, perform nonzero nonlinear learning, compact the residual, and promote once more. Compare every subsequent forward value, actual boundary gradient, explicit-path update and residual state against an independent uncompressed source that performs the same orthogonal split. A fixed hand-selected t can first establish executability, but task-conditioned selection is required before describing this as adaptive construction. Require an actual nonlinear response after learning, not just `c != 0`; for example check a finite nonadditivity witness on held-out inputs. This is a finite mechanism test, not evidence of broad generalization or meta-learning superiority.

**The mandatory strongest alternative is small-factor refactoring plus conventional morphism/AD:** factor H into a source of width `rank(H)<=d`, apply the identical invariant mode split, retain the same nonlinear exceptions and train with ordinary AD. Count its factorization, proposal, retained state and updates. It already preserves future factor learning without carrying redundant h. Removal of redundant width is therefore not the proposed acquisition advantage. If both systems do the same work up to representation constants, record that result; do not rename the coupling into a principle.

**Do not recycle an exposed nonlinear path merely because its current c is zero.** If c remains trainable, its future gradient depends on the nonlinear feature and is part of the new action interface. Folding it into H would repeat the exact error K was designed to avoid. Only an explicitly narrowed action contract, a retained sufficient capsule, or a stated approximate criterion could justify deletion.

The success counterfactual is concrete: the compact learner can construct genuinely nonlinear computation from retained learning state, then keep learning and construct again without recovering discarded source details. This removes one important structural blocker to recursive construction. It does not by itself establish a new principle or advantage over the small-factor morphism alternative. A pass earns a substantive substrate extension and a better-defined acquisition question; a miss identifies the exact extra state or unavailable information.

## Weakest link and reversal

The most important uncertainty is whether selecting useful construction interfaces and retaining their learning state creates an acquisition/resource advantage over adaptive small-factor refactoring with the same task information and action opportunities. No existing result answers that.

Reverse this decision toward CONTINUE on the stronger coupling if the cycle is exact, truly creates nonlinear behavior, preserves the new edit interface through the second construction, and exposes a concrete organizational benefit not supplied equally by the small-factor alternative. Reverse toward PIVOT or CLOSE_BRANCH for K as the main research mechanism if useful actions repeatedly require unrecoverable source distinctions, retained exceptions/discovery costs erase the compactness, or the strongest plausible outcome remains an ordinary engineered hybrid with no meaningful acquisition distinction. A successful replay alone is insufficient for FINISH under the fixed ambition.
