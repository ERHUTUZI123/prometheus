## Formation-v0: a real search law, with a shared transfer consequence

The new algorithm is specific. It lazily samples a complete descriptor-indexed action table, keeps each chosen action fixed through the scored batch, selects tables by endpoint performance and full cost, and distills the distinct used entries into a neural proposal. The weighted fitting update is explicitly a search heuristic, not an unbiased event-level policy-gradient claim. Its independent actions at different descriptors are different search coordinates from v2's whole-W-coupled deterministic emitter. Neither method starts with named binding/call/copy rows.

The nominal-support proof is sound under its restrictive assumptions. A state whose support is at most k cannot remember membership among k+1 distinct opaque atoms: swapping an omitted atom with a fresh one leaves that state fixed but changes the correct suffix answer. The m! association count also correctly requires association information somewhere. These arguments establish a real memory burden. A variable-size exact-pointer heap or an input-sized grid falls outside the bounded-support assumption, and the pointer bits pay for the associations. Neither proof selects graph topology over those rivals.

The comparison then supplies the requested actual transfer case. If a common lexical closure/apply/return interface forms, a new H-after-repeated-N composition can use the same finite kinds of local rule rather than an N-to-H adapter or a depth-specific policy. The endpoint family genuinely distinguishes capture and non-idempotent behavior. This is a meaningful conditional account of reusable organization; the finite training labels neither force that interface nor identify physical copies.

The fixed-register rival matters more than the word RAM. Its controller chooses among a constant set of register/gate sources, READ follows stored handles, and heap fields retain the relevant environment and continuation identities. It can acquire a common closure/call interface and remove the **same** future adapter/depth decisions. It need not learn an m-way classifier over all live addresses as depth grows. The generic nominal payload adapter and coherent exploration are explicitly declared adaptations, not invented claims about the original implementation. The hand record process proves representability and locates its decisions; it does not prove equal learning costs or a trained RAM evaluator.

I also checked the final cost correction. N applied to B returns a closure retaining B through p. Thus repeated N produces owned values with `Ci=C_(i-1)+c`, not uniformly bounded values. At each formation, actual Project/Cons duplicates an environment containing that predecessor. These captures alone therefore require Ω(k²) D/constructor events. No full upper count is needed for that lower bound. A shared heap adds one predecessor pointer per closure and follows a linear selected chain. This remains an execution distinction, not a neural acquisition theorem.

The attempted extensions were not merely dismissed by name: frozen interfaces can also be retained by ordinary subroutines; failed endpoints do not reveal a correct context split without extra information; deterministic confluence does not force a sequential pointer learner to search schedules. V0's actual remaining differences are search priors, constants and error geometry. They may matter empirically, but this pass identifies no particular important acquisition prediction attributable to them. Parking its next implementation is warranted. Closing the architecture itself would not be.

## Outside-principle: laws and state can be acquired, but the finite construction is covered

This reserve did change the proposed acquisition object: retain a relation among trajectories, then impose a boundary, compose and hide variables to construct an executable use. Its finite mechanism is inspectable rather than a nonlinear-feature placeholder.

The noiseless moment rule is correct: `aᵀCa=Σ(aᵀzi)²`, so the kernel contains exactly the annihilators of the observed span. Recovering a true behavior requires that span assumption; a new boundary cannot create missing excitation. Likewise `Lw w+Lh h=0` projects exactly to `N Lw w=0` when N spans the left nullspace of Lh. After consistency is checked, `ker[R;P]⊆ker T` gives unique target values. The recurrence example and its inverse boundary calculation are correct. Approximate eigenvalues, conditioning and changed port meanings do not inherit these exact conclusions.

[Willems's original behavioral treatment](https://homes.esat.kuleuven.be/~sistawww/smc/jwillems/Articles/JournalArticles/2007.1.pdf) supplies the source principle: relations precede an optional input/output partition, interconnection shares variables, and state supports concatenation of legal pasts and futures. Its elimination result concerns the stated linear differential behavior and solution spaces; it explicitly warns about nonlinear elimination. The reserve's finite matrix proof is narrower and does not need an unproved extension of that theorem.

The post-freeze pass also repairs the state-formation gap explicitly. On admissible pasts, the nonempty completion sets `F(p)={f:Rf f=−Rp p}` obey

`F(p)=F(p') iff Rp(p−p')=0`.

The forward implication follows by taking a common completion and subtracting; the reverse gives identical equations. The quotient by the restricted kernel and its rank-factorized coordinates are valid sufficient state for this finite future relation.

The recurrence counterexample is load-bearing. For `x_(t+2)=a x_(t+1)+b x_t`, histories (1,0) and (0,1) have equal next values when a=b=1 but different following values. A one-step quotient is insufficient for continued execution. The two-step map has matrix `[[b,a],[ab,a²+b]]`, with determinant b². It retains two dimensions when b≠0; for b=0 it reduces to one except the further a=0 degeneracy. Extending finite-horizon sufficiency to arbitrary continued execution still requires an actual closure/realization argument.

This is a serious constructive state-formation rule. It also has direct same-information coverage: an ordinary identified linear relation can compute the identical moment, nullspace, rank factorization, quotient and compiled boundary operations using the same observations and arithmetic. That correspondence reproduces the actual method; it is not universal simulability or an invented identical neural learner. Distilling these coordinates into an encoder changes neither fact. A compact useful nonlinear law basis remains an important OPEN problem, but no further law for acquiring it has been supplied by naming it.

The comparison correctly preserves distinctions from old branches. The finite relation/solver does not contain the branch-history state of constraint transport, and the future-execution quotient does not establish preservation under later neural updates as required by K's learning-interface problem. I do not infer that all relational mechanisms are identical. The actual finite reserve is covered nevertheless.
