## Actual derivation and causal limits

The history derivation's exact finite law is correct:

`U=mean[-e D-D^2/2]`,

where D is the actual whole-program output change. For a consumer conditionally affine in one independently owned cell, `D=c_j d_j`, giving its stated quadratic response utility. The response-basis compression, residual-error bound and multi-recipient cross term follow directly. Exactness requires the stated response representation/current checkpoint; public-probe fit alone does not certify off-probe behavior. Stale labels/summaries do not become current by timestamping them.

Two gaps limit a stronger interpretation of the pilot:

1. **Source-content necessity is not isolated.** The implemented `features(j,d)` contains recipient response, realized displacement and recipient residual/curvature history, but no source context or history. A source packet can itself carry experience, so this absence is not a refutation. It does mean that the current predictor is exactly a contextual value screen for candidate function changes; unrelated but feasible proposals might obtain similar benefit. Random recipient selection does not test packet content.
2. **The full-trajectory local comparison also changes label allocation.** Learned routing chooses which recipient receives the fresh audit batch and then native SGD; the local arm chooses that recipient randomly. Positive paired gains isolate immediate packet effects on their selected audits, but the final loss difference does not isolate transferred knowledge from active allocation of subsequent supervised learning. Summing adaptive selected-audit gains also does not create a common-objective policy ranking. The untouched common evaluation is the appropriate overall metric, with this treatment scope retained.

If a source-content audit were later scientifically necessary, arbitrary nine-dimensional norm-matched noise would be a weak null: real packets lie near a smooth tanh response family and may distill much better. A null should arise from a shadow source update with shuffled/sign-randomized per-example credit on the same paid source batch, with actual genuine source SGD still committed in both arms, matched norms/realizability and all extra work charged. This is a possible causal check, **not the next main action recommended here**. It cannot by itself turn value screening into a consequential new principle.

## Strongest constructive update-relation variant

I gave the stronger hypothesis a concrete reconstruction rather than rejecting the word “relation.” Let each position have a calibrated observable response basis `E_j` with orthonormal columns. Learn an orthogonal latent frame `O_j=O_psi(h_j)` and set

```
A_j = E_j O_j,
z_i = A_i^T d_i,
requested d_j = A_j z_i.
```

The local actuator realizes the requested response through its declared distillation/edit procedure. Actual realization error and source components outside `col(A_i)` remain evidence; they are not silently transferred. The frame/history is learned or revised from paid paired external effects, not from hidden group labels. A more general full-column-rank variant uses `R_ji=A_j A_i^+`; at a common checkpoint,

`R_kj R_ji=A_k(A_j^+ A_j)A_i^+=R_ki`.

Thus it has an explicit composable update interface on the represented subspace. Rank/conditioning and a common latent gauge matter. Independent unconstrained fitting of local factors does not automatically identify their relative frame. A scalar utility audit does not supply a whole target map; identifying it needs adequate directions, recurrence/context assumptions and paid calibration. RLS or a Bayesian posterior is a possible estimator only after that observation model is specified.

There is an exact strong relation-scramble control. Replace `A_j` by `A_j R_j` using independent orthogonal `R_j`. In the orthonormal construction this preserves every local projector `A_j A_j^T`, rank, encoded-source norm and requested destination norm while disrupting cross-position correspondence. One common rotation at all positions leaves every route unchanged and supplies a gauge check. Finite actuator realization can still differ with direction, so requested norm equality is not a claim of identical realized packets.

This is a genuine constructive rule and a clean causal experiment. It does **not** currently justify further spending as the main principle line. Its strongest plausible success is transferable alignment of latent update coordinates, learned through a finite-effect meta-objective and revised with contextual state. An equally informed latent-factor/contextual optimizer implements exactly these encoders, decoders, state updates, `O(Mpr)` factor storage and local realization. This is an explicit mechanism correspondence, not a universal-simulation objection or a claim that a full implementation already appears verbatim in one paper.

The scramble would show that learned relative alignment matters; it would not show that the organization changes an important limitation beyond existing latent-factor/meta-learning. It can even disrupt a learned common code for ordinary recipient descent without demonstrating that source-specific experiential content is necessary. Source-content and recipient/data-selection questions therefore remain distinct from alignment.

MSR/MSR-Joint, task-affinity estimation, learned gradient transformations, contextual optimizers and latent-factor models are not purity objections. They identify what the strongest current prospective result amounts to. No new asymptotic acquisition guarantee, new compositional capability, reduction of a specified hard information requirement, or total-resource advantage has been derived for this variant. Cheap amortization could be important, but the present rule supplies no reason that its attainable advantage would transcend that established class. Under the latest user steering, a clean alignment test is not enough reason to preserve the abstraction as the main route.
