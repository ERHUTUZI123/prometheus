## Four corrections that matter for execution

1. **Use the full implicit derivative.** For a general relation `Q(z,u,theta)=0`, the continuous transport is

   `z_dot=-Q_z^(-1)(Q_u u_dot+Q_theta theta_dot+kappa Q)`.

   The v0 formula with bare `u_dot` applies only to `g(z)-u`. For the polynomial above with variable epsilon it becomes

   `z_dot=Q_z^(-1)[(z-3)u_dot+epsilon_dot-kappa Q]`.

   Real-coordinate implementation uses the corresponding two-by-two Jacobian. Omitting Q_u changes the actual path lift; omitting the parameter term during growth does not implement retention through the coefficient homotopy.
2. **Migrate retained state rather than reselecting it.** Start from the old roots at u=1, add the new root, and continue epsilon from zero to its chosen value with a documented branch identification. Independent root solving/reseeding at each stage cannot by itself establish memory retention. Initial roots may be established once; subsequent execution retains and transports the selected branch.
3. **Report scale-aware conditioning.** Raw `|Q_z|` and `|Q|` depend on multiplying the same relation by a nonzero factor. Record root separation, actual predictor/corrector work, Newton correction scale `|Q/Q_z|`, and control sensitivity `|Q_u/Q_z|` or real-coordinate equivalents. Numerical residual alone is not proof that the right sheet was tracked, especially near a new branch point. Require bounded step/corrector termination and an explicit failure path.
4. **Keep the preservation scope exact.** The old fixed loop is protected uniformly by the contour bound. The new gate needs an explicit nonsingular handle/circle and measured separation/conditioning. Finding a different new loop separately at each epsilon is not proof that one frozen new loop survives all later coefficient changes. Protecting that gate in a subsequent growth step would require including its corridor in the next certificate. No extra repeated-growth experiment is required for this first scoped check.
