# A concrete bounded-semantics repair, not yet a formation principle

AGENT PROPOSAL / RECONSTRUCTION by root after reading generated interaction-law v0. This changes an actual state/transition rule. It is not a claim of new resource semantics or a MAIN promotion. No experiment.

## Why the rule changes
Uncensored local diamond does not make a global time/work cutoff confluent: two independent redexes can leave different partial graphs depending on which one runs before the cutoff. Peak live-node caps can permit shrink-then-grow while rejecting the reverse. A schedule-invariance claim must include its finite resource semantics.

## New state and local transition
Give every agent (code z, integer fuel c>=1), fixed code precision, principal/auxiliary ports. Initial graph is finite with Phi_0=sum_v c_v<=B. Keep semantic graph emitter K_theta(z,w) independent of fuel. For a proposed replacement of k<=4 agents, a separate learned allocation head proposes positive integers c'_1,...,c'_k. Accept only if

 sum_j c'_j <= c_1+c_2-1.

For k=0 the empty sum is0. Unaffordable pairs are disabled, rather than resampled until an affordable but semantically different action appears. All payload codes and pointer changes remain the proposed content law. A frozen, deterministic allocation head receives only the pair codes/parent fuel and proposed RHS; it cannot inspect a global remaining counter, time or allocation ID. Encoder, code/rule emitter and allocation head can be trained by the same episodic task/work/space loss, with all sampled choices charged. No efficient acquisition consequence follows from specifying those networks.

## Exact finite property
Every accepted replacement reduces Phi by at least1. Thus at most B accepted rewrites occur, and every live graph has <=B agents because c_v>=1. Adding fuel to a state makes a genuinely different execution input; no guarantee of optimal allocation or monotone success is assumed.

At a fixed state, distinct eligible active pairs have disjoint agents. Their kernels read only those agents, so each local acceptance decision, RHS and fuel allocation is unchanged by executing the other first. Port gluing commutes. With sufficient admission to execute both individual events (now ensured by *separate local fuel*, not a shared quota), their common successor has identical fuels and graph up to fresh-name renaming. Disabled pairs cannot be recharged by another pair under this rule, since their agents are untouched. The same local diamond applies to the fuel-augmented state. Termination plus this diamond yields one normal form for every schedule. A final observation can declare a resource failure if a semantic active pair remains disabled. This does not claim that every task succeeds.

Kernel-evaluation/admission cost is separate from accepted rewrite count. A worklist evaluates each newly formed pair once, caches a disabled result while its agents remain unchanged, and has O(B) pair births because a bounded replacement has a bounded number of incident wires. With fixed d/precision/RHS bound this gives a finite evaluation bound; it is not a wall-clock or memory-safety proof of untrusted code. Actual test code would still use the external campaign process/OS limits. Training histories, random-field identity costs and decoding are additional. No hardware-energy advantage is claimed.

Stochastic laws need the separate causal-key coupling conditions in the candidate; ordinary shared iid draws preserve distribution but not same-seed coupling. A global stopping policy, graph-global attention, semantic use of allocation IDs, or early output ignoring active garbage does not inherit the exact statement.

## Why this is not the answer yet
The repair turns uncontrolled shared resource censoring into a local state discipline. A resource-annotated conventional interaction reducer or token-conserving graph machine can obey the identical rule and learn the same allocation head. Unused fuel can strand useful work; global scheduling can be more efficient. This may be a useful bounded architecture, but its strongest currently justified effect is operational consistency/termination, not a new acquisition principle. It should not displace the scientific objective with safe runtime engineering. Primary affine/resource-typing comparisons would be needed before any novelty claim. No new validation is justified solely by this proof.
