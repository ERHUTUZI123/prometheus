# First focus decision, after all three independent v0 freezes

This is a scientific selection artifact within the authorized run, not a new
living project plan. No candidate is declared original or successful.

## Principal candidate: R, constructing computational resources from laws

Success counterfactual: if task feedback can acquire finite operational laws
whose generic execution constructs a reusable memory organization, a learner
need not be restricted to a designer's initial stack/counter/slot catalogue.
The potentially consequential change is the acquired generative organization
and its later use, not simply increasing the number of stored states.

V0 exposed a confusion: finite observations cannot universally establish an
external algebra, and a runtime enforcing a guessed rule cannot validate that
rule as empirical truth. R's substantive v1 changes the question: presentations
define proposed INTERNAL actions; external task feedback selects useful ones.
It must still explain a real acquisition/retention mechanism beyond ordinary
program, ADT or architecture search, with an explicit compiler rather than an
undefined law-to-resource oracle. Existing allocators, arithmetic, neural
policies and rewriting are legitimate primitives.

Single current gap: useful presentation acquisition plus explicit preservation
of retained old operations when the execution state space is extended. Strong
controls receive the identical rule language, runtime, observations and cost
budget; ordinary equation/program search is not handicapped by withholding it.
A supplied stack-law normalizer or fixed-law identity test does not decide this
gap. Before major implementation, v1 must state the differentiating effect or
concede that only a known-style reconstruction is currently available.

R was selected for this prospective change in what resource organization is
learned, not because finite rewriting is easy to enumerate. The matched-rival
analyst is examining direct prior coverage before costly construction.

## Protected, different alternative: K, learning execution algebra

Success counterfactual: a learner might construct useful general computation,
identify a cheaper exact execution algebra for part of it, and repeatedly reuse
that released computation budget in later construction without relearning old
semantics. Its resource is an exception interface in tensor execution, not R's
generative state/memory space.

Function-preserving port changes, matchgate compilation, hard-residual
localization and sparse-exception simulation all have concrete priors. The
v1 derivative-insertion repair makes off-core learning explicit but is not new
automatic differentiation. One serious constructive pass is protected on the
remaining repeated construction/recompilation consequence, compared with the
same deterministic compiler plus ordinary task learner. No planted known-basis
recovery or zero-residual identity check will be inflated into that result.

## P: preserve evidence, do not make it the major implementation

P's exact full-state frame requires conserved context, which is too strong for
globally attracting dynamics even when an apparently reusable suboperation
exists. Its latent objective also admits a rescaling false-success route.
Both attacks are precise and retained. Physical-state loss repairs scaling but
does not discover a useful abstraction or eliminate the invariant obstruction.
Continuation-observational repair overlaps existing state-abstraction theory.
P remains a distinct conceptual alternative, not another full project.

## Evidence boundary

Independent v0 contexts and primary reading were real; file/data separation
remains instruction-only. No neural acquisition, paradigm-level result or
novelty follows from these freezes or the supplied-law finite sanity probes.
The next scientific action is constructive v1 plus precise nearest-rival
comparison, followed by a test touching the surviving claim and a fresh neutral
reconstruction. If no consequential difference survives, the run may deliver
that outcome rather than retreat to an unrelated conveniently provable problem.
