## Judgment

The growth law is a concrete mechanism for adding a new coupled operation while retaining declared old branch permutations. Two explicit task-feedback laws can be built around it. Neither currently supplies a convincing advantage over a matched ordinary learner. The important residual is open, and has become narrower: learn productive relation couplings from evidence without simply translating an already inferred state machine or Boolean condition into geometric form.

## Law A: distinguishable-history feedback drives a branch split

State consists of the relation P_theta, the current branch z, acquired loop generators, and an observation set of histories and suffix responses. The environment provides finite episodes with an input/action sequence and an observed output at declared query points. Reset or homing access must be stated and charged. A loop inverse resets its own reversible action, but does not magically reset an arbitrary environment.

The growth relation is more general than v0's F(z,u)=g(z)-u form. For a general learned F_theta(z,u), the actual real-coordinate transition is

    dz/dt = -[D_z F_theta]^{-1}(D_u F_theta du/dt + kappa F_theta).

It again gives dF/dt=-kappa F wherever D_z F is invertible. For Q=(z-3)(z^2-u)-epsilon this uses Q_z=3z^2-6z-u and Q_u=3-z. A structured coefficient learner can fix the leading z coefficient to one to prevent the zero-residual collapse. This is a representation restriction; an arbitrary residual MLP trained only on positive zeros would need an additional noncollapse/identification mechanism.

1. Maintain empirical response signatures r(h)=(y(h e):e in E) for a finite suffix set E. These are observations; do not insert an equivalence oracle unless one is actually provided.
2. If two histories h1,h2 currently share an internal branch but an observed suffix e gives y(h1 e) != y(h2 e), the current state is insufficient for those observations. This is a decisive aliasing witness, not evidence that the entire representation is globally inadequate.
3. Propose one new branch with Q=(z-r)P-epsilon phi under the old-corridor preservation condition. Identify it at the resting boundary by an isolating neighborhood. The old branch can now be separated from the new one by a new transport operation C.
4. Train a context selector on the witnessed histories to choose when to insert C. Search bounded candidate paths for C, starting from a neighborhood of the newly created discriminant pair, and check the actually transported endpoint. C is not supplied the correct endpoint by an oracle; training episode feedback evaluates it.
5. Accept only when the new controller+relation reduces the declared training error, after charging all queries, fitting, structural proposals and path-tracking steps. Preserve the old corridors and semantic root identifications as part of the retained mechanism. Held-out histories and longer compositions are separate evaluations.

This law is operational, but it has a decisive rival. The observation that h1 and h2 must be different internal states is exactly the information used in ordinary automaton refinement. Angluin's original L* paper explicitly forms state candidates from suffix-response rows and refines inconsistent rows. A matched symbolic learner can make that distinction directly. Under membership/equivalence-query access, mature automaton-learning results are stronger than anything derived here; with ordinary sampled episodes, neither side gets an unearned exact oracle.

There is also a realizability limitation. Safe closed-loop monodromy acts by permutations. It cannot implement a genuinely many-to-one state update on a fixed finite fiber. Ordinary automata can merge states. Reversible simulation can retain additional garbage/history or use an external reset, but that memory/resource cost must be included. Thus Law A does not automatically learn an arbitrary finite-state environment in the proposed reversible execution substrate.

Conclusion for Law A: a complete acquisition procedure can be stated, but its productive causal step is classical state distinction. The geometric part supplies a representation and a retention certificate; no learning advantage follows.

## Law B: a continuous surrogate learns when a gate should occur

For the binary-register witness, let a_theta(c) be a smooth learned coefficient of control registers c and drive the target with

    z_t^2=1+a_theta(c)x.

At rest x=0, so z_t is +/-1. Fix a loop around x=-1 and away from x=-1/3. The gate identity is flat as a function of a_theta as long as no critical value crosses the loop. Therefore directly differentiating discrete flip error cannot train a new flip condition in a safe region.

A supplied training example indicating whether a target should flip provides a continuous surrogate: fit a_theta(c) toward one coefficient interval whose critical value lies inside the loop when flip is wanted, and another interval whose critical value lies outside when flip is not wanted. For example, targets 1 and 3 correspond to the hand-derived witness. A gradient learner can fit this classification surrogate, then gate identity becomes robust within its respective safe interval. The underlying relation changes continuously while the already correct examples' discrete operations can remain fixed.

Again the strongest rival is direct. Fit the same predicate on c and execute a conditional XOR/NOT, using the same training labels and a threshold with the same margin. This rival acquires the same conditional operation without root continuation. If a_theta uses known control incidence and a fixed scalar encoding of flip labels, the construction is a geometric encoding of an ordinary learned gate condition. Calling the coefficient a neural relation does not create a new computational acquisition principle.

This also identifies a hidden-answer danger: deriving the desired conditional coefficient formula from target labels and then claiming the system discovered a Toffoli mechanism would be false. The register witness proves representability only.

## What a stronger acquisition law would have to exploit

The remaining route is to acquire a local relation from independently available continuous evidence, then obtain useful operations from its global continuation structure without receiving their branch-permutation labels. A classical learned-model plus monodromy compiler is the matched baseline. It should receive the same relation samples, derivative access, internal coordinates and ability to intervene. A topology-aware neural organization could still be useful, but the contribution would require a specific acquisition or resource consequence beyond that compiler.

There are immediate obstacles. Finite pointwise regression does not establish a covering over unobserved corridors. Arbitrary real neural maps need not retain isolated complex branchpoints; the holomorphic polynomial structure of the proof is an inductive bias. A neural extension needs local isolating-neighborhood/C^1 control, or a compatible structured representation. A polynomial coefficient learner can satisfy the representation restriction, but then low-degree polynomial fitting is an especially strong simple baseline. Counting only the later cheap loop execution would hide the expensive acquisition step.

No such stronger law is supplied in this version. The missing step has not been renamed self-organization or deferred to an unexplained meta-controller.

## Narrow scientific claim that remains supported

Conditional on the stated relation and separation bound, an additive structural mutation can create a new interacting generator while preserving a finite declared old operation set up to semantic branch identification. The proof permits internal coordinates to move, and explicitly charges the conditioning cost of small couplings. That is a mathematical construction about computational organization; it is not evidence of effective neural acquisition, task generalization, better evolvability, or novelty over the relevant topology/continuation literature.

Root's planned bounded growth test can check the implemented preservation/new-transposition process. A successful result would support this construction in the tested numerical regime. It cannot resolve Law A's automaton rival or Law B's learned-predicate rival.

The next single scientific decision is whether to derive an evidence-driven coupling law with a real consequence over the matched learned-relation compiler. If no such consequence is available, this candidate should remain an inspected construction and the campaign should pursue a different main mechanism. This is a recommendation about this candidate, not a declaration that the campaign is finished.
