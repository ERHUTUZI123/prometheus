## Important limitation and actual new rule

A continuous implicit module generally has both state and parameters; learning parameters can move/destroy its stored computations. Instead encode a discrete operation in continuation of a retained branch of F(z,u)=0 along a closed control path. Protect selected old path classes while adding a new branch and a new operation. The success counterfactual is editable continuous computational organization with persistent executable operations, not another endpoint predictor or a fixed supplied gate alphabet. Whether this changes any consequential acquisition/resource limit versus explicit automaton growth is OPEN.

State consists of actual retained z, control u, relation coefficients theta, protected control paths plus their branch-label anchors, and a bounded constructor/controller. For a parameter-changing relation the correct executor is

    z_dot = -F_z^{-1}(F_u u_dot + F_theta theta_dot + kappa F).

All complex quantities stand for two real coordinates. Wherever the real Jacobian is invertible, dF/dt=-kappa F. The often simpler F_z^{-1}u_dot formula applies ONLY to F=g(z)-u, not arbitrary new relations. Finite numerical tracking still needs correction and error checks.

The constructor's designed structural action is

    P(z,u) -> Q_epsilon(z,u)=(z-r)P(z,u)-epsilon phi(u).

At epsilon0 the old subsystem and an unused constant branch r coexist. At a regular resting control, migrate existing state through coefficient homotopy epsilon:0->epsilon1, using the parameter derivative in the executor, rather than independently resetting to a newly solved root. A new branch crossing outside old operational corridors splits into branch values. New loops may connect the new branch to old ones while old selected loops preserve their permutations.

The actual learning/acquisition law is NOT established by this designed action. A possible finite constructor uses task failures to propose r,phi,epsilon and loop handles, reject loss of protected corridor margins, measure real new task performance, and retain an extension only if its paid construction/continuation/retention cost is justified. This is a transparent proposal-selection scaffold; it must beat or differ consequentially from an equally informed continuation/automaton constructor before counting as a new learning principle. No source of desired gate labels or extra information is assumed free.

## Preservation lemma, scoped proof

Let Gamma be a finite compact old control-path family. Assume P's roots are simple there, and r is uniformly separated from them. At each u choose disjoint disks surrounding each old root and r. If on EVERY disk boundary and u in Gamma,

    |epsilon phi(u)| < |(z-r)P(z,u)|,

then the same inequality holds for s epsilon,0<=s<=1. Rouché gives one zero in each moving disk throughout homotopy. Matching branch labels at the resting control by that homotopy therefore identifies old permutations with their original action plus a fixed new branch. This preserves discrete branch semantics, NOT exact root values, readout coordinates or correctness of arbitrary unrelated paths.

If P(r,u*)=0 transversely, A=P_z(r,u*) and B=P_u(r,u*) nonzero, and phi(u*) nonzero, local coordinates yield

    Q approximately A zeta^2 + B v zeta - epsilon phi(u*).

The formerly disconnected crossing splits into two simple critical values v approximately +/-2 sqrt(-A epsilon phi(u*))/B. An isolating loop around one gives a new transposition. This local asymptotic statement requires nondegeneracy and does not identify a useful task operation automatically. New branch/control separation tends to zero with epsilon; protection is not unlimited noise immunity.

## Exact quantitative witness for the central check

Take P=z^2-u, r=3, phi1 and old path |u|1 with resting u1. Initially roots are -1,+1,3 (the last added but disconnected). Around old roots +/-sqrt(u), use disks of radius1/4. On their boundaries,

    |(z-3)(z^2-u)| >= (1/4)(7/4)(7/4)=49/64.

Around3, |z|>=11/4 and |z^2-u|>=105/16, hence the bound105/64. Thus ANY epsilon in(0,49/64) satisfies this explicit retention condition. It is a sufficient bound, not the actual sharp threshold.

For Q=z^3-3z^2-uz+3u-epsilon, the critical values are obtained by

    2z(z-3)^2+epsilon=0,
    u_critical=3z^2-6z.

Two new values lie near9 +/-2i sqrt(6epsilon); the old value moves near epsilon/3. A small isolating loop about an upper new critical value, with a safe handle from resting control1, exchanges the positive old branch and the new branch. Together with the old negative/positive exchange, this supplies noncommuting operations after growth. Both the handle and actual branch assignment must be checked; a picture of circles is not enough.

For small epsilon, resting roots move by +epsilon/8,-epsilon/4,+epsilon/8 respectively. An assertion of unchanged numeric outputs would therefore be false even when the protected operation is retained. Coefficient homotopy must transport decoder anchors too if the readout is branch identity.

## Learning tension and actual alternatives

Within a nonsingular homotopy class, a closed-loop endpoint permutation is locally constant. A loss depending only on that discrete identity has zero ordinary deformation gradient there. Acquiring a new operation needs a finite class-changing proposal, a structural event or an additional continuous learning signal; pure smooth optimization of the protected gate label cannot be assumed to work.

Classical continuation executes the SAME F with the SAME state, coefficients, precision, paths and feedback and is the strongest allowed executor, not a weak baseline. A finite-state/controller library can retain measured permutations and invoke the same paths under identical actuation constraints. If only digital answers matter and continuous actuation is not required, a finite-state table can bypass root tracking and be cheaper. The current construction does not establish an advantage against either. Its modest central claim is a concrete growth/retention primitive with nontrivial global coefficient changes, not a foundational learning algorithm.

The planned bounded check tests this primitive and its conditioning boundaries, not a static cubic monodromy rerun or an acquired neural topology.
