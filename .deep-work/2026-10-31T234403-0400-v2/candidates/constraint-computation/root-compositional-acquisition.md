# Autonomous topological operation formation: the actual compositional target

RECONSTRUCTION / AGENT PROPOSAL, after the explicit topology MAIN decision. Same V2. No completed growth experiment is repeated. This is a new scoped derivation and acquisition interface, not a novelty or usefulness claim.

## 1. Preservation can cover all old programs, not only a finite test list

Let an old regular fiber have m labeled states and a finite library A of closed control paths. Each a acts by an actually executable permutation sigma_a. After one certified coefficient growth, identify old/new root states by the SAME carried coefficient homotopy iota, not by independent nearest-root relabeling for each program. Suppose the corridor certificate gives

    sigma'_a o iota = iota o sigma_a,
    sigma'_a(c) = c,

for every old generator a, where c is the added state. Then for EVERY finite old word w in generators and their inverses,

    sigma'_w o iota = iota o sigma_w,
    sigma'_w(c) = c.

Proof: inverse permutations preserve the same invariant subset, hence the identities also hold for inverse letters. Apply the identity one letter at a time; the common iota cancels at successive interfaces. This is induction on word length. Our convention is that executing a then b acts as sigma_b o sigma_a. Repeated growth composes these embeddings, so the same statement applies to every previously retained old word.

Thus, under the actual holomorphic/corridor assumptions of root-growth-v1, certifying finitely many acquired generators can preserve an infinite language of their compositions. It does not preserve arbitrary unregistered paths, real-coordinate output values or functions that read intermediate branch coordinates. A finite-precision executor also needs its own path-tracking margins: this algebra does not prove unbounded-length numeric reliability or free correction/reset.

This is a standard group-action consequence of the covering/continuation construction, independently reconstructed here; not a new theorem attributed to the cited papers or a machine-checked proof.

## 2. One acquired interacting operation can enlarge the executable group

Assume the old group G acts transitively on its m states. The extension above fixes c. If the learner discovers ONE new loop acting as a transposition tau=(c,i), then the extended library generates S_(m+1), the full permutation group on the enlarged fiber.

Proof: for any old j, transitivity supplies an old word g with g(i)=j. Since g fixes c,

    g tau g^-1 = (c,j).

This displayed identity uses ordinary function composition. With the left-to-right executed-word convention above, the corresponding program is `g^-1, tau, g`. Executing `g, tau, g^-1` instead swaps c with g^-1(i). The distinction changes a concrete compiled word, although transitivity gives the same group-generation conclusion.

These star transpositions generate every old-state transposition as

    (i,j) = (c,i)(c,j)(c,i),

and transpositions generate every permutation. This argument requires an actual new transposition, not merely a visually different trajectory or a nonzero endpoint displacement. If a discovered loop only acts inside an already accessible orbit or has an unrecognized product of cycles, the conclusion does not follow.

The previous manually constructed cubic supplies the m=2 witness only. It did NOT learn tau or prove that this acquisition step scales. The new task is to acquire such a coupled operation from paid observations/task feedback, preserve its executable path and semantic identification, and subsequently compose it. Fixed-alphabet braid-word search alone does not acquire tau.

All fixed-fiber operations remain reversible permutations. Many-to-one functions need extra retained state, allowed measurements/resets or a different execution regime; count those resources. This result does not establish universal computation, an efficient implementation of S_(m+1), or superiority over a discrete permutation table.

## 3. What must actually be learned versus supplied

An internal constructor may own relation coefficients theta and a structural grammar such as

    Q=(z-r)P-epsilon phi(u).

Owning its code means those coefficients and derivatives are legitimate information for the same-information conventional rival. We must not hide them from the baseline, invent a regression expense for it, or call their later identification a new learning achievement. The designed grammar and the retained branch are supplied substrate; selection of a useful coupling/path/operation from actual feedback can be acquired.

Separately, learning an external relation from local observations can supply an internal model. Promoting that model into a computing relation is a valid different construction, but external system identification is not automatically invention of the system's own relation. Finite local samples constrain unseen monodromy only under a justified shared model class or regularity/certification assumption. A monic finite-dimensional polynomial learner offers one explicit prior; an unconstrained residual MLP does not inherit it.

For an owned-relation acquisition test, the constructor state must include (theta, carried physical branch, anchor/version correspondence, protected path library, observed operation effects, task evidence, candidate budget). Its proposals must choose at least a coupling or a new path/operation, rather than receiving the correct new loop from a human critical-root calculation. A solver/critical-point calculation is allowed and must be paid; using known mathematics does not invalidate autonomy, but neither does it constitute a novel learning algorithm.

Learning can select finite structural/class-changing proposals from task reward and use smooth optimization for residual, margin, path length and conditioning within an established class. A loss depending only on the discrete endpoint permutation is locally constant under safe loop deformation, so ordinary local gradient descent cannot silently serve as a new-class discovery rule.

## 4. Concrete strongest alternatives and what the result would mean

**Same continuous actuation:** a conventional source-aware polynomial/continuation planner receives the same relation/coefficients, derivative probes, task examples, starting/reset access and permitted growth grammar. It can identify critical geometry, construct/trial paths, learn their permutations, and search their composition graph. Charge each of these actions. Success against an arbitrary weak gradient baseline would not establish an advantage over this rival.

**Digital functional computation:** a conventional learner stores the same discovered permutations and composes them as explicit tables. Old tables can be extended with a fixed added state, retaining every old word by precisely the induction above. If only digital answers matter, it need not pay continuous root transport. Compare that legitimate implementation. If the task instead requires manipulating the SAME continuous substrate, tables may plan/invoke the learned paths but do not receive a free branch-setting actuator.

The immediate empirical question is therefore autonomy and retention under declared information, not presumed novelty: does the constructed learner actually choose a useful extension and discover an interacting operation without a teacher path, then execute new compositions while retaining old semantics? The broader scientific question is what limitation, if any, this organization changes beyond the matched conventional constructor. Both remain open; a successful acquisition demonstration is intermediate evidence, not a paradigm declaration.
