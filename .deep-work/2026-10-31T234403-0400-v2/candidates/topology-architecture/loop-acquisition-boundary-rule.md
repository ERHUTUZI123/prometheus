## Judgment and success counterfactual

There is an explicit way for terminal feedback to train a neural controller **through changes of monodromy class**, rather than first learning a permutation and then rendering it as a loop. Represent operations by controller-generated paths. Smooth the terminal loss over path coordinates, and obtain its gradient from the loss jumps at paths that meet the discriminant. Protect only previously admitted paths against such events. New paths may cross between classes during parameter updates and acquire operations outside the subgroup generated by the admitted library.

The consequential prospect is a shared trainable program generator that acquires executable operations without allocating a dense learned transition map for each operation, while preserving all words of old admitted operations by a geometric condition. The proposed improvement is in **acquisition credit and retention versus shared plasticity**, not in a supplied polynomial, a new root solver, or a claim that geometry is cheaper than digital permutation application. This would bear directly on how a neural network constructs and improves its internal mechanisms if the boundary rule can acquire useful new classes at competitive total cost.

**The derivative construction uses established discontinuous-objective methods. Its mathematical existence is not a novelty claim.** The unresolved scientific residual is whether the monodromy-specific event structure gives a useful learning organization or acquisition/retention cost advantage over the ordinary methods specified below. No result here establishes that advantage or passes TODO 2. State-capacity growth and general input binding are also not solved by this first rule.

## 1. Exact computational object and the supplied substrate

For a first implementable instance, supply a fixed, internally authored relation

$$
F_D(z,u)=z^D-Dz-u=0,\qquad D\ge2,
$$

with base control $u_*=0$. Its $D$ resting roots are distinct. Its finite critical controls are

$$
\mathcal C_D=\{-(D-1)\zeta:\zeta^{D-1}=1\},\qquad B=|\mathcal C_D|=D-1.
$$

The polynomial, its derivatives, these critical controls, and the continuation algorithm are **supplied computing primitives**. Neither system gets credit for rediscovering its own source. Every rival receives exactly the same source/event geometry. More general fixed covers could replace this example; they need a computable discriminant/event interface, not an assumed global certificate for an arbitrary MLP.

The persistent learned state is

$$
\mathfrak S=(\theta,\mathcal A,\mathcal D,\mathrm{receipts},\mathrm{budget}),
$$

where $\theta$ is a shared neural path controller, $\mathcal A$ is the set of admitted operation inputs, and $\mathcal D$ contains the actual terminal examples allowed by the task. The runtime state is the carried root $z$ (or its resting sheet label), the current control, and the program position. A simple first scope fixes input sheet encoding and output sheet readout; learning those interfaces requires separate protection and must not be hidden in this rule.

For operation input $x$, the controller emits $M$ complex vertices

$$
a_\theta(x)=(v_1,\ldots,v_M)\in\mathbb R^{2M},\qquad
v_0=v_{M+1}=u_*.
$$

Their piecewise linear interpolation is a based loop $\gamma_{a_\theta(x)}$. The same $x$ uses the same loop at each occurrence. Self-intersections of a control loop are allowed; intersection with $\mathcal C_D$ is not. A fixed coordinate box, $M$, precision, minimum executable clearance, and continuation-step limit are externally bounded in any actual protocol.

The actual local transition along a regular segment is implicit continuation,

$$
\dot z=-F_z^{-1}F_u\dot u
=\frac{\dot u}{D(z^{D-1}-1)},\qquad F_D(z,u)=0,
$$

with a numerical predictor/corrector and its residual/separation checks charged in implementation. A symbol word concatenates the generated loops **without resetting the carried sheet between symbols**. The decoded terminal state supplies the model output. No desired permutation is an intermediate teacher or a trainable operation table.

For a terminal example $(s_0,w,y)$, define the bounded loss

$$
L(a;s_0,w,y)=\ell\!\left(R\bigl(\rho([\gamma_{a(w)}])s_0\bigr),y\right).
$$

The convention in this display is functional composition in execution order; implementation must retain its own explicit matrix convention. The loss is constant on each safe path-coordinate chamber because its arguments use sheet identity, not moving root coordinates. Continuous execution-quality penalties could be added, with their usual within-chamber gradient, but they do not supply the class-changing signal below.

### Feedback is terminal, and counterfactual evaluation costs real work

In the supervised scope, $y$ is the supplied terminal label for the word and initial state. Multiple candidate internal loops may be run against that same label. This does not reveal intermediate target states, the correct loop, or the correct whole permutation. Each candidate run, continuation solve, training-example access, and loss computation is counted.

In an interactive environment, evaluating the two sides of an event means two actual paid executions with the corresponding reward and a legitimate reset/common starting state. A stored reward cannot label a different environment action for free. The supervised and interactive scopes are different contracts; only the first is needed to implement the proposed diagnostic.

## 2. The failed first learning rule and the targeted repair

**ATTACK.** Differentiating the exact noiseless terminal sheet loss through a regular loop gives zero throughout every safe chamber. It therefore cannot select a new operation class. A smooth numerical root coordinate can have a nonzero gradient while the desired discrete computation remains unchanged. This is exactly the old campaign's locally-constant-operation obstruction; it is retained, not reinterpreted as success.

**REPAIR.** Optimize a distribution of executable path programs and differentiate its mass crossing class boundaries. Let $a$ collect the coordinates of the currently unadmitted operation inputs appearing in a training word. Admitted operation inputs are not given class-changing exploration noise. Repeated occurrences of the same new input share the same perturbed loop in an episode.

Use a bounded, continuously differentiable kernel, for example

$$
p_\sigma(t)=
\begin{cases}
\dfrac{1+\cos(\pi t/\sigma)}{2\sigma},&|t|<\sigma,\\
0,&|t|\ge\sigma,
\end{cases}
\qquad
J_\sigma(a)=\mathbb E_{V\sim\prod_i p_\sigma(V_i-a_i)}L(V).
$$

This is a **different, explicitly stochastic training objective**. Deterministic capability is checked separately at the mean controller path before admission. Smoothing does not prove deterministic success or donate correct class labels. Compact support keeps the contemplated programs inside a declared bounded coordinate box. It also makes the limitation visible: if no informative boundary is in support, this gradient is zero.

Hold $V_{-j}$ fixed. Write the terminal loss along the remaining coordinate as $f_j(s)=L(V_{-j},s)$. Suppose its distinct regularity boundaries are $b_1<\cdots<b_n$, with jumps

$$
\Delta_r=f_j(b_r^+)-f_j(b_r^-).
$$

Ignoring measure-zero nongeneric slices and assuming the stated exact continuation semantics, the coordinate derivative is

$$
\boxed{\quad
\partial_{a_j}J_\sigma(a)
=\mathbb E_{V_{-j}}\!\left[
\sum_{r=1}^{n}\Delta_r\,p_\sigma(b_r-a_j)
\right].\quad} \tag{1}
$$

**RECONSTRUCTION, informal proof.** On a slice, the piecewise constant function is $f_j(s)=c+\sum_r\Delta_r\mathbf1_{s>b_r}$. Convolution with $p_\sigma(s-a_j)$ replaces each step by its tail probability. Its derivative with respect to the location $a_j$ is $p_\sigma(b_r-a_j)$. Integrate over the other coordinates; bounded loss and the finite event bound below justify this step in the stated finite-polyline scope. Boundary coincidence/tangency and numerical uncertainty require explicit handling, rather than using this almost-everywhere argument as a floating-point certificate.

Backpropagation now uses

$$
\nabla_\theta J_\sigma
=\sum_j\partial_{a_j}J_\sigma\,\nabla_\theta a_j.
$$

Thus the topology class changes because terminal feedback changes **probability mass between executable monodromy classes**, not because an ordinary derivative changes the value of a locally constant map. The state transition itself still executes an actual loop, never a soft average of mutually incompatible permutations.

For deterministic terminal-example loss, the slice sum in (1) is also the conditional expectation of the ordinary location-score estimator

$$
G_j(V)=L(V)\,\partial_{a_j}\log p_\sigma(V_j-a_j)
$$

given $V_{-j}$. Integration by parts gives the same jump sum; the kernel vanishes at its support endpoints. With finite second moments, conditional expectation implies $\operatorname{Var}(\mathbb E[G_j\mid V_{-j}])\le\operatorname{Var}(G_j)$. This is a precise variance-reduction consequence **before accounting for the extra interval evaluations**, not an equal-cost advantage. An ordinary boundary-aware optimizer obtains exactly this consequence too. Stochastic environmental rewards require estimating interval mean losses, and the simple variance comparison no longer includes that additional sampling noise for free.

## 3. Why the boundary term is computable without enumerating all classes

Move one real coordinate of one raw vertex $v_k(s)$. Only its two adjacent segments change. For a fixed critical control $c$, an event on the segment from $v_k(s)$ to its fixed neighbor $v_l$ satisfies

$$
\det(v_k(s)-c,v_l-c)=0,
\qquad
(c-v_k(s))\cdot(c-v_l)\le0. \tag{2}
$$

The determinant is affine in $s$, so each adjacent segment/critical-control pair gives at most one generic candidate event. Test the segment condition, remove duplicates, and sort. There are at most **$2B$ candidate events per raw coordinate**, independent of the number of homotopy classes or the word length. If a higher-level tied coordinate moves several vertices, its larger event bound must be counted; the $2B$ statement is for a raw vertex coordinate.

Although a new input may occur many times in a word, the event set of its common loop is unchanged. The **jump loss** is evaluated on the whole word, so its effect includes every occurrence and the complete subsequent computation. A transposition event before a long suffix can consequently obtain credit from the actual terminal label without an intermediate-state teacher.

At a generic crossing of one simple branch value, the two primitive loop classes differ by insertion of a local square-root loop transported along a handle. Consequently $\Pi_+\Pi_-^{-1}$, with a consistent based-loop composition convention, is a conjugate of that branch's transposition. The handle/prefix determines which semantic sheets are involved. That identification must come from actual continuation or an honestly paid equivalent interpreter; the coordinate event position alone does not reveal the correct permutation jump. Equation (1) uses the measured terminal loss difference rather than inventing this missing sheet correspondence.

There is no need to execute infinitesimally close to a singular loop. Between consecutive event values the loss is constant. Choose an interior representative of each interval intersecting $[a_j-\sigma,a_j+\sigma]$, check executable clearance, and execute it once. Its loss supplies the adjacent jumps. This replaces unstable $b\pm\epsilon$ evaluation by finite-clearance chamber representatives. If an interval is too narrow to support a permitted finite-precision execution, its contribution is unresolved; silently skipping it makes (1) a biased approximation.

One transverse sample and one coordinate need at most $2B+1$ full-program terminal evaluations for all jumps, plus $O(B)$ event calculations and sorting. Sampling a coordinate $j$ with known probability $q_j>0$ and returning $e_j\hat g_j/q_j$ gives a stochastic full action-gradient estimator. Sampling events with probabilities and inverse-probability weights can reduce the number of paired executions; event detection, probability construction, and estimator variance still cost resources. No low variance is proved merely by writing the estimator.

This local event bound is the concrete reason to investigate this representation: a path-coordinate derivative can be assembled without enumerating a potentially enormous collection of complete operator classes. It is **not** a lower bound against discrete search, permutation inference, or a compiler. Those methods can sometimes solve the task directly in polynomial time.

## 4. Retention and useful shared changes

Before a proposed shared neural update $\theta\to\theta'$, compute each admitted input's old and proposed vertices. Let

$$
\delta_x=\min_t\operatorname{dist}(\gamma_{a_\theta(x)}(t),\mathcal C_D),
\qquad
d_x=\max_k|v_k(\theta',x)-v_k(\theta,x)|.
$$

The sufficient transaction test

$$
d_x<\delta_x\quad\text{for every }x\in\mathcal A \tag{3}
$$

keeps the straight interpolation of all corresponding vertices, and hence every interpolated segment point, away from the discriminant. All endpoints stay at $u_*$. Therefore each old loop remains based-homotopic to its previous version. Its sheet action remains identical, and so does every word made from admitted inputs under the fixed sheet encoding/readout. Apply backtracking or a more exact swept-segment test if (3) fails; charge every rejection, output computation, and certificate check. This test can be conservative and can halt new acquisition.

Crucially, (3) constrains **only admitted inputs**. The path for an unadmitted input may change class between successive parameter snapshots. The learner does not execute a singular intermediate program when it updates its weights: it executes separately checked regular candidate programs on either side. On admission, the deterministic mean path must meet task success and a frozen executable-clearance condition; it then joins $\mathcal A$. The same neural parameters remain trainable, subject to the old path constraints. Protection of a merely sampled subset of a continuous input domain does not protect unobserved inputs; a uniform input-domain bound would be an additional obligation.

This can preserve an unbounded language of old words by checking finitely many old operation inputs. That compositional argument is standard and is not this candidate's novelty. Here topology additionally supplies the **formation events** in (1)–(2). An ordinary rival is allowed to use both the same compositional protection and the same events.

Persistent dense old transition tables are unnecessary for the ideal rule. One can compute old vertices before a proposal and use transient storage, rather than freeze a complete neural backbone. This still costs old-input enumeration, controller outputs, temporary vertices, and certificates. Any stored paths, permutation caches, optimizer state, admitted-input embeddings, or old model snapshots must be counted. Arbitrary $K$ independent permutations require at least $K\log_2(D!)$ bits to distinguish; geometric real coordinates do not evade that information requirement. A parameter benefit needs task structure and finite-precision accounting.

### Analytic existence witness: a new class with unchanged parameter count

This is a hand-designed three-sheet witness of the rules, not a learning experiment or an advantage claim. Let

$$
F_3(z,u)=z^3-3z-u,\qquad
\mathcal C_3=\{-2,2\},\qquad
z_*(0)=(-\sqrt3,0,\sqrt3),
$$

and label these resting sheets $0,1,2$. For one scalar $a$, use the triangular based loop

$$
\gamma_a:\quad 0\longrightarrow a+i\longrightarrow a-i\longrightarrow0.
$$

For $|a|<2$ it encloses neither critical control and has identity action. For $a>2$ it encloses only $2$; the sheets that coalesce at $z=-1$ are $0,1$, so its action is $A=(01)$. For $a<-2$ it encloses only $-2$; the coalescing sheets at $z=1$ are $1,2$, so its action is $B=(12)$. These statements follow by deformation to a small local square-root loop and real continuation from $u=0$; they have not been checked numerically here. $a=\pm2$ are excluded singular paths.

Suppose an old input has acquired $B$. A new terminal example starts on sheet $0$ and requests sheet $1$. The old admitted subgroup $\{I,B\}$ cannot perform it. A newly acquired $A$ can. Once $A$ is acquired, executing $A$ then $B$ sends $0$ to $2$, while $B$ then $A$ sends $0$ to $1$: the new action interacts with the retained one.

For the new input's 0–1 terminal loss,

$$
L(a)=\mathbf1_{a<2}\quad(a\ne\pm2).
$$

The class event at $-2$ has zero loss jump on this example; the event at $2$ has jump $-1$. Thus

$$
J_\sigma'(a)=-p_\sigma(2-a).
$$

At $a=1,\sigma=2$, the exact repaired derivative is $-1/4$, whereas the noiseless derivative is zero. Only the terminal outcomes of regular interval representatives are needed to obtain the jump; the learner need not receive the target transposition.

Now use a shared two-parameter controller

$$
a_{old}=w_0-w_1,\qquad a_{new}=w_0+w_1,
\qquad (w_0,w_1)=(-1,2).
$$

Initially $a_{old}=-3$ and $a_{new}=1$. The boundary gradient for the new example is $(-1/4,-1/4)$. A gradient-descent step changes both shared weights equally, leaving $a_{old}$ exactly $-3$ and increasing $a_{new}$. For example, the compatible parameter path $(-1,2)\to(0,3)$ takes $a_{new}:1\to3$ and forms $A$ while retaining $B$, with no additional controller parameters. New-path class boundaries may be crossed between parameter snapshots; the old path never changes.

The deliberately aligned features in this witness make a useful protected direction available. A general neural controller may have no such direction or may find it only expensively. An ordinary linear controller with a threshold/class interpreter matches this scalar witness exactly. The witness establishes internal consistency of the proposed acquisition/retention rule, not historical originality or a competitive result.

## 6. Strong ordinary rivals and the minimal technical unknown

The following rivals have equal task feedback, source, critical controls, detected event positions, interval representatives, permitted memory, reset access, and total evaluation budget. They may use cheaper digital execution when only digital answers are required; continuous actuation must not be imposed after seeing results.

1. **Ordinary discontinuous-program optimization.** Use the same path-coordinate decision predicates and the established boundary-gradient method, with a digital branch/permutation interpreter after honestly paid action identification. This is the nearest learning-rule rival. It may reproduce the learning trajectory exactly. That would locate any effect in boundary-aware program learning, rather than a unique continuous-realization benefit. Historical coverage still requires checking a genuinely pre-existing specific rule; copying this candidate into the rival is a mechanism attribution control, not a novelty proof.
2. **Discrete class/word search.** Give a conventional learner the same discoverable event-adjacency moves and their paid terminal evaluations; allow beam search, coordinate class descent, active permutation inference, and bounded word search. For small $D$, enumerate the relevant finite permutations/classes when affordable. No weak ordinary-AD baseline can replace this rival. The cubic witness should be solved immediately by it.
3. **Shared neural program generator with protected discrete operations.** Let an ordinary controller learn and emit compressed gate words or factored permutations from the same data, use the same old semantic contracts, and share/compress parameters. This tests whether geometric parameter tying adds anything beyond ordinary program generation. Private modules/freezing are valid additional retention strategies, with all storage counted.

The **minimal load-bearing unknown** is whether the event-weighted terminal jumps remain informative and inexpensive enough under realistic compositional feedback to train the shared controller, while the old-path feasible region retains useful directions. A finite event formula alone does not answer it.

There is a sharp adverse case. If all reachable one-event neighbors have the same terminal loss and improvement needs coordinated crossings, local boundary contributions can vanish; transverse smoothing finds them only with the probability of the other required changes. That probability can shrink exponentially. Sparse 0–1 reward, small clearance intervals, many old admitted inputs, and large $D$ may defeat this rule. No extra shaped reward or oracle is assumed to repair that case.

Conversely, if terminal examples distinguish useful adjacent changes, (1) evaluates their contribution directly even when an ordinary finite difference inside the current safe chamber is identically zero. This is a concrete, limited acquisition mechanism. At best it is a reasoned prospect for topology-aware program learning; it is not a proof that topology outperforms the ordinary event-aware alternatives.

**Discriminating prediction:** event geometry should matter through the *availability and cost of informative loss jumps*. A win only against ordinary AD is insufficient. If the ordinary event-aware or discrete learner matches the acquisition/retention frontier, that closes a topology-exclusive advantage claim for this version while leaving the checked boundary construction intact.
