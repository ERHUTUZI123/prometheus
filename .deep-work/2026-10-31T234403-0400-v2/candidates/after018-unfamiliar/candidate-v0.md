## Theory entry and the question it changed

SOURCE: Yves Lafont, *Interaction Combinators*, Information and Computation 137 (1997), 69–101; original-paper PDF body §§1.1–1.2, 1.5–1.7, 2.1, especially pp.73, 79–81. Reading record in the paired source artifact. Its local interaction format makes distinct active pairs disjoint. That is an execution property; it does not provide learning, termination, useful interfaces, or a semantic correctness guarantee.

AGENT PROPOSAL: replace learning a globally scheduled sequence of instructions with learning the **alphabet of local interacting operations**, and permit an operation to have a literal principal-net expansion into already available operations. Then new interactions can be generated by reducing two expansions together. A neural proposal mechanism would search the new definitions and interactions. The possibly substantive addition over generic learned rewrite rules is the expansion/shortcut relation below, not immutable rules by themselves. Whether this is merely known partial evaluation/library learning is OPEN.

## Concrete state and execution

At adaptation generation k, let `L_k` contain finite symbols with fixed arities and a partial unordered-pair rule table. A runtime state is a finite port graph `G`: each cell has one principal port and ordered auxiliary ports; every port belongs to one wire, and external ports specify the I/O interface. The fixed executor chooses any active principal-to-principal cell pair `(a,b)`, removes the pair, instantiates the stored finite RHS `R_ab`, and reconnects its ordered free boundary to the pair's former auxiliary wires. The RHS must use each boundary port once. There is at most one rule for each unordered symbol pair, with the appropriate self-pair symmetry.

A rule may create cells, including its own operation type. Hence an acquired operation is a finite recursive transition schema, not a cached answer for one input. The executor and graph grammar are human supplied; the rule bodies and newly allocated operation types are the proposed objects of learning. An external host cell-count/step limit would terminate a trial. No such trial is authorized or executed here.

### Principal-net expansion and an actual semantic law

Let a new symbol `a` of arity n have an expansion `E(a)` with n+1 boundary ports and the same distinguished root. Replacing all new cells by these principal nets defines expansion `E(G)` into an older alphabet. For each proposed active-pair shortcut `a >< b -> R_ab`, impose the open-boundary obligation:

`join_root(E(a), E(b)) ->*_old E(R_ab)`.

Here `->*_old` is an explicit finite reduction in the old frozen rule table, with every external boundary retained. It is not a test on sampled arguments. Replacing one such shortcut inside an arbitrary surrounding graph reproduces the same local expansion reduction; thus the old-level behavior is preserved for that step. The claim is conditional on a valid expansion and witnessed reduction. It does not show all new operations have discoverable useful expansions, nor that all interactions normalize.

The concrete formation possibility is: propose a principal subgraph as an operation definition, expand a pair of proposed operations, reduce it offline to an open-boundary RHS, and retain that RHS as a shortcut with its reduction witness. Charge discovery, witness storage, code size and expansion/reduction costs. Neural proposals alone are not evidence of a new semantic law. This proposal is **not yet a completed acquisition algorithm**: how end-task gradients/reward efficiently identify a useful new symbol rather than only a compilation opportunity remains unconstructed at freeze.

## Worked executable computational process

The following is a hand-derived representational check, not a learned result. Data constructors are `N` of arity 0 and `C0,C1` of arity 1; a list is a constructor chain with each head's auxiliary port wired to the tail constructor's principal port. An invented `F` has arity 1: principal=input, auxiliary=result. Its pair rules implement binary-list negation:

`F >< N -> N_at_result`

`F >< C0(t) -> C1(F(t))`

`F >< C1(t) -> C0(F(t))`.

The last two lines are port-graph notation, not hidden functional evaluation. Their two free boundary ports are old result `r` and old tail `t`. Create `F'` and the opposite constructor `C'`; connect `F'.principal` to `t`, `F'.result` to `C'.tail`, and `C'.principal` to `r`. This RHS has no internal active pair. The `F,N` RHS is a single `N` connected to `r`.

For input `C0(C1(N))`, the first rewrite emits `C1` and sends `F` to `C1(N)`; the next emits `C0` and sends `F` to `N`; the base rule closes the output as `C1(C0(N))`. Three steps realize this input; structural induction supplies the evident finite-list procedure in the mathematical representation. No program has been executed and no statistical learning claim follows.

An additional mechanism can allocate phase symbols `P0,P1`, each arity 1. `Ps >< Cb(t) -> P_(s xor b)(t)`, with the result wire preserved, and `Ps >< N -> B_s` for arity-zero output constructors `B0,B1`. For `C1(C0(C1(N)))`, phases are `P0,P1,P1,P0`, then output `B0`. This shows what a newly allocated control-state distinction can do; the phase semantics and rules were derived here, not discovered by a learner. A learned principal expansion for a fused `Q = parity ∘ F` could avoid materializing the intermediate list, if the open-boundary shortcut obligations can be constructed. That last clause is unfinished, not a proved efficiency advantage.

## Success counterfactual and strongest attack

HYPOTHESIS: if a neural learner can efficiently acquire such new operation definitions, search later tasks in the expanded alphabet, and retain their explicit local meanings, it would learn an executable computational vocabulary and its interactions rather than only adjust direct input/output behavior. A broad payoff would require useful acquired abstractions to reduce **total future acquisition cost**, not merely make existing programs execute faster. Fixed old operations remain computationally sufficient; the contemplated difference is finite-budget acquisition and organization.

ATTACK: the concrete construction presently looks like learned graph rewriting plus dictionary learning, partial evaluation, and immutable program libraries. A neural program synthesizer with the same data constructors, recursion, training examples, stored programs and total resource budget can implement the worked examples. If the only payoff is ordinary fusion or amortized compilation, this is not an adequate principal line for the project's ambition. Confluence also offers no semantic correctness, missing-rule recovery, or bounded resource guarantee.

The strongest same-information alternative should therefore be a neural recursive program/library learner with the same operation definitions and expansion witnesses, plus ordinary inlining and partial evaluation. No superiority is assumed. Closest actual learning precedent has not been substantively entered at this freeze; do not substitute remembered names for original reading. Parent-provided after014 bodies must be compared next before any continuation of this architecture.
