Do NOT infer a Euclidean distance contraction by assuming products of positive definite matrices are symmetric positive. Use residual V directly.

    0<s <= |P_z| <= S,
    |P_u * u_dot| <= B,

and their moving boundaries have |P|>=beta>0. Obtaining these uniform bounds costs actual source/interval work; finite samples are not proof. Choose r0<beta so the residual sublevel component |P|<=r0 remains in the intended root neighborhood. Initial state must actually lie in that component; its preparation/error verification counts.

Let J be the real Jacobian of the holomorphic map P. It obeys JJ^T=|P_z|² I. On |P|=r>0,

    dV/dt = -(J^T P)^T M_theta (J^T P)
            + Re(conj(P) P_u u_dot) + (J^T P)·eta
           <= -m s² r² + r(B+S nu).

Consequently, on the boundary r=r0,

    dr/dt <= -m s² r0 + B+S nu.

If B+S nu < m s² r0, the residual component is invariant. It cannot exit through a root-neighborhood boundary because that would require |P|>=beta>r0. The state therefore tracks the same lifted root component during the whole control path. When the operation returns home, decoder correctness follows if the component lies within the declared anchor/readout margin. A paid home dwell can shrink residual further if required. ## Learning-specific repair identified during constructive cross-check

The first displayed LL^T mobility has a real dead start: at A_theta=0 its derivative with respect to A is zero. Ordinary task gradient alone cannot learn anisotropy from that exact parameter value. This is a limitation of that parameterization/initial condition, not a need for a new semantic state or a proof the family cannot adapt. Nonzero initialization is legitimate; a smooth direct bounded symmetric parameterization is another explicit repair.

In two dimensions, let shared network outputs be b=(b1,b2), define c=(m+Mmax)/2, r=(Mmax-m)/2 and

    B=[[b1,b2],[b2,-b1]],
    M_b = c I + r B/sqrt(1+b1²+b2²).

Its eigenvalues are c +/- r ||b||/sqrt(1+||b||²), strictly inside(m,Mmax), and trace is2c. At b=0, dM=r dB is nonzero, so a task-derived gradient can change direction from an isotropic start. The normalization and network derivatives cost real operations; no new primitive is claimed. A fixed trace is an architectural/model choice, NOT an established physical energy budget. If the only allowed constraint is M<=Mmax I, the scalar Mmax I is a fully legal strong alternative. A putative directional-learning gain must report actual force/work/latency/certificate tradeoffs against it, not remove it using an invented budget.

For a deterministic inspected executor, the actual gradient can be specified without a hidden intermediate teacher. Let f_theta=-M_theta grad V. State sensitivities obey

    dS_theta/dt = (partial_x f_theta) S_theta + partial_theta f_theta,
    partial_theta f_theta = -(partial_theta M_theta) grad V.

A terminal measured smooth error plus declared running work yields the ordinary sensitivity/adjoint learning update. Discrete branch success is evaluated separately; no derivative through the rounded branch label is fabricated. In an unknown physical plant, exact model derivatives are not free observations: identification, finite-difference probes, stochastic control or model-error bounds are required and shared with controls.
