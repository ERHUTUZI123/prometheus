## Completed root derivation: operation-class retention and actual retention are different

RECONSTRUCTION, analytic proof, not machine verified. Suppose H* and H are Hermitian on the same finite-dimensional modeled Hilbert space and integrable over[0,T], with unitary propagators U*,U. Put V=U*^dagger U. Then

    dV/dt = -i U*^dagger E U* V,
    ||U(T)-U*(T)||_op <= integral ||E(t)||_op dt.

The inequality follows by integrating dV and unitary invariance of operator norm. It includes leakage in the full modeled space. If the ideal restricted gate is the certified G_a in the common idle code, this bounds worst-input gate-state error by epsilon_a; state infidelity is at most epsilon_a^2 (capped by1). This is a conservative sufficient bound, not an exact cost/fidelity prediction.

For an executed word w=a_L...a_1, a telescoping product of unitary differences gives

    ||U_w-G_w|| <= sum_(j=1)^L epsilon_(a_j).

Thus finite generator certificates can cover arbitrary old words ALGEBRAICALLY, but a demanded maximum word length/error is essential for useful execution. Preparation/readout errors add to the bound. If shared parameter updates physically move the stored code and each migration has error mu_k, add sum_k mu_k and all migration work. Pinned idle is a concrete way to avoid that particular migration, not a theorem that all continual costs vanish.

This identifies a constructive leverage point: amortize TOPOLOGICAL semantic checking separately from refresh of EXECUTION/calibration envelopes. It also identifies a dangerous failure mode: a single gap/class certificate cannot certify finite-time old capabilities. A shared learner could preserve every ideal gate and still destroy actual performance. That is a diagnostic requirement, not a veto on topology research.

## Complete analytic warning example: fixed gap does not bound finite-time error

RECONSTRUCTION, not a new numerical run and not a universal counterexample to topological computing. In units hbar=1 consider the two-level rotating-field model

    H(t)=(Delta/2)[cos(omega t) sigma_z + sin(omega t) sigma_x],
    T=2pi/omega, Delta>0.

The instantaneous gap is Delta throughout and the Hamiltonian returns to itself. In the rotating frame R=exp(-i omega t sigma_y/2), the effective Hamiltonian is (Delta sigma_z - omega sigma_y)/2. Starting in an eigenstate of sigma_z, final excitation probability is exactly

    p_exc = omega^2/(Delta^2+omega^2)
            * sin^2[pi sqrt(Delta^2+omega^2)/omega].

At omega=Delta this is .5*sin^2(pi sqrt2), not zero. The loop/gap information alone therefore cannot be substituted for a finite-time execution certificate. This spin example is geometric/adiabatic, not a non-Abelian topological computer; its role is isolating the missing execution obligation. ## Additional root diagnostic consequence: a conservative bound can hide real safe learning

The Duhamel bound is sufficient, not always useful. If E is the entire omitted counterdiabatic term of a bare adiabatic implementation, its norm integral can stay constant as T grows; using only that bound can incorrectly make the feasible learning region look empty. That is failure of the sufficient verifier, not evidence that adiabatic retention is impossible. A useful C_exec may instead exploit gap/derivative structure, phase cancellation, verified integration or direct task feedback with declared statistical limits.

The rotating-spin example gives an exact elementary check on this distinction:

    p_exc <= omega^2/(Delta^2+omega^2)
          <= (2pi/(T Delta))^2.

Thus T*Delta >= 2pi/sqrt(p_budget) suffices uniformly without exploiting lucky resonant zeros. Increasing a SHARED gap can make a shorter execution meet the same error budget while preserving the path geometry. This is a real allowed adaptation direction in that model, but not free learning/retention: with H=(Delta/2)n·sigma, the control proxy integral ||H||² dt = Delta²*T/4 increases as1/T when the sufficient fidelity product T*Delta is held fixed. It exchanges latency for amplitude/work rather than proving a TOTAL-cost reduction. The proxy is explicitly a modeled control functional, not measured quantum energy consumption.

This calculation changes the next test design: compare resource frontiers at matched amplitude, error and old-task criteria; do not call faster execution cheaper if the cost moved into a growing gap/correction field, and do not reject useful learning solely because an overly coarse safe bound stays large.
