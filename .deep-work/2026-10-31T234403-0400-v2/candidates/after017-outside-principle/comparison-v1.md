## One constructive pass at the missing formation step

Willems's state-construction discussion offers a more definite repair than the phrase learn nonlinear features: derive a retained internal state from which past distinctions matter for possible futures. This can create a state variable rather than assume one. I now make that rule explicit in finite dimensions and test what it buys.

Assume a learned finite behavior relates past p in R^a to future f in R^b:

    B = {(p,f): R_p p + R_f f = 0}.

Restrict p to the admissible set P_adm=projection_p B so that each future-completion set

    F(p)={f:R_f f=-R_p p}

is nonempty. Define p~p' iff F(p)=F(p'). Then

    p~p'  iff  R_p(p-p')=0.                         (1)

**Proof.** If the right side holds, the equations for f are identical. Conversely, choose f from the nonempty common completion set; subtract its two equations. Thus a sufficient retained state is s=R_p p. Restrict R_p to P_adm and use a rank factorization to retain only independent coordinates. The state space is the explicit quotient

    P_adm / (P_adm intersect ker R_p).              (2)

**Formation law.** Update the trace moment, recompute its kernel law as in v0, split that law at the chosen history/future boundary, and form (2). This synthesizes which history distinctions the modeled future can still test. A neural encoder can be fitted to the computed state coordinates, but such distillation is not what establishes sufficiency and provides no new computation in this derivation.

The rule does more than append a chosen nonlinear feature: the newly installed coordinates follow from the learned behavior. It also exposes why a finite convenient verifier can answer too weak a question.

### Load-bearing worked case: one-step sufficiency fails

Let a true scalar mechanism satisfy

    x_(t+2)=a*x_(t+1)+b*x_t.

For p=(x_t,x_(t+1)), retaining only the next observable gives state a*x_(t+1)+b*x_t. For a=b=1, histories p=(1,0) and p'=(0,1) have the same next value 1. Their following values are 1 and 2. Thus the one-step quotient merges histories needed for continued execution. It is not a valid two-step computational state.

With a two-step future, the deterministic future map is

    [x_(t+2)]   [ b       a    ] [x_t    ]
    [x_(t+3)] = [ a*b   a^2+b ] [x_(t+1)].         (3)

Its determinant is b^2. When b!=0, the correct two-step quotient has dimension two: no history direction can be removed. When b=0, the future depends only on x_(t+1), except for the further degenerate a=0 case. The formation rule therefore does discover when one state variable is sufficient, provided the learned behavior and horizon are correct. It cannot compress away an actually necessary distinction merely because an early prediction task does not test it.

Equations (1)–(3) are a hand derivation, not a computational experiment. They establish sufficiency for the stated finite future relation. Extending the quotient to indefinitely continued execution requires an actual closure/Markov argument or enough behavior to identify a finite realization. A fixed short horizon does not supply that automatically.

## Why this constructive repair still closes the finite reserve

The strongest ordinary alternative receives the identical windows and descriptors. It can compute the identical C, R_p, R_f, rank factorization, and state (2), then realize the recurrence with ordinary state-space coordinates. It uses exactly the same signal directions and arithmetic. No extra semantic labels, latent-state oracle, future-task labels, or free validity calls are needed. Thus the proposed state-formation repair also has a direct same-information implementation by the alternative.

The repaired scheme has created an internal state, but it has not established a different acquisition consequence. If a neural encoder is added only to reproduce s, the alternative receives the same encoder and distillation examples. If a more flexible feature map is optimized to make (2) small, a latent-model/implicit-solver learner can receive that same map and objective. This last observation does not rule out all learned representations; it shows that a new formation rule or resource consequence has not been supplied just by moving the burden into the map.

There is an additional distinction from the Fundamental Question's improvement requirement. The behavior above concerns subsequent execution under one relation. If learning changes neural port meanings or the transition/update law, equal states under (2) need not remain equivalent. A behavioral quotient over the whole admissible update family would need those updates represented and learned or specified. The current linear compiler does not obtain that family from raw task outcomes. Adding it would be a different scientific claim, close to the explicitly declared learning-interface issue in K, not a free consequence of the original theory.

## What has and has not been learned from the pass

The original theory gave two concrete, inspectable changes in computational organization: laws can precede input/output assignments, and state can be constructed from behavioral distinctions. Both are meaningful principles already present in system realization. The finite kernel learner, elimination compiler, and future-equivalence quotient are legitimate reconstructions of them.

The important remaining question—how to acquire a compact, reusable internal law basis for substantial nonlinear computation—has not become a mechanism merely because it can be stated. The current REINFORCE descriptor policy is explicit but provides no reason that useful descriptors are accessible. Adding arbitrary nonlinear features, a rank penalty, or an unconstrained neural residual does not repair that absence. The nonlinear x*h=1 counterexample, observational ambiguity, inverse-conditioning warning, and port-semantic drift from v0 continue to apply.

No further parity/recurrence demonstration or training run is warranted as evidence of a new principle for this version. Such a run could verify implementation, but it would not discriminate the candidate from its exact ordinary realization. Closing this finite version preserves the independently derived negative boundary without claiming that a stronger formation mechanism cannot exist.
