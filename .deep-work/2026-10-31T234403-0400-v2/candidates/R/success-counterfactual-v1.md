# R v1 success counterfactual — before further implementation

**AGENT RECONSTRUCTION; HYPOTHESIS.** The learner constructs the semantics of its own internal actions. It need not discover a supposedly true external algebra. The scientific question is whether learning a finite, executable presentation of an internal resource can make acquiring and composing new algorithms materially easier than learning programs over a fixed memory organization.

If successful, a neural learner would receive ordinary task interactions, propose low-level transition rules and internal constructor signatures, and acquire a reusable resource whose state space can grow beyond encountered examples by an acquired rule. Neither the target equations nor a stack/queue/counter catalogue would be supplied. A small transparent term-graph runtime would execute the acquired rule itself; no compiler would infer a data structure from a semantic oracle. The exact guarantee would be that the constructed resource executes its own accepted operational laws at every allocated size. Task usefulness and successful acquisition would remain empirical claims.

The contribution would need to concern **acquisition organization**: learning resource constructors and their operators should change subsequent algorithm acquisition under matched initial capability and total resource accounting. A stack at longer lengths is insufficient if ordinary synthesis over the same grammar finds the same rules just as easily. A neural proposal distribution is not itself a new mechanism. Better task accuracy caused by a larger state store is also insufficient.

What remains beyond the closest checked sources:

- **Phillips 2021 shared monoid/free representation:** internal operational specifications are selected for usefulness, not recovered as the common external schema of already learned action tables. The computational acquisition advantage is still unshown; the high-level algebra/representation concept is covered.
- **CALF 2022:** both the internal signature and its execution rules can change; the target is not an algebra for an already fixed functor. CALF's exact termination assumptions are not being imported into infinite generated memory.
- **Knuth–Bendix 1970/ordinary equation discovery:** the checker and normalizer are existing scaffold. The candidate selects a useful internal operational theory from task feedback, rather than deriving consequences of supplied axioms. If this is merely standard inductive functional/ADT synthesis with a neural guide, that is the correct classification.
- **Hand-memory catalogue:** the proposal grammar contains generic symbols, variables, typed ports and local term patterns, not templates named stack, queue or map. A catalogue under the same total cost remains a strong baseline. The generic term graph already supplies a great deal of memory power and must not be hidden.
- **Generic history:** histories remain possible representations. Learned cancellation, retrieval and constructor rules must improve measured acquisition/execution costs rather than merely rename that history. Keep a history interpreter with the same observations and allocation capacity as an early baseline.

No further training run is justified merely by this formulation. Before one, select a task family in which the acquired resource matters to later algorithm learning, specify an equally expressive ordinary synthesis baseline with the same rule language, and show why a plausible positive outcome would exceed amortized search over a conventional DSL. At present that final scientific distinction is OPEN. The v1 construction below repairs an epistemic/implementation gap; it does not yet establish a new learning principle.
