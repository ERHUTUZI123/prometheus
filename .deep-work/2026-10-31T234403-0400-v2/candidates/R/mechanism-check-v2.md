## Judgment

The exact check supports a concrete internal interaction: an edit useful for one primitive can require additional credit channels when composed with other primitives. A generic algebra/module closure constructs the missing channel. The check also exposes the central failure mode: a new recurrent interaction can force the carrier to become full dimensional. It does not establish a cheaper learning system or a novel algorithm.

**Mechanism:** retain an execution algebra A and an edit carrier M closed under inserting computations before/after an edit. Paired composition `(a,m)(b,n)=(ab,an+mb)` transports actual computation and shared directional credit. Select useful missing edit directions from task feedback, then close their consequences instead of keeping only the initiating local edit. Scoped operational contracts can constrain which variations preserve an existing mechanism.

**Largest scientific gap:** acquire useful low-cost closure and parameter ownership from task feedback, and amortize all acquisition/compilation/probing costs against a competent sparse forward-AD/RTRL implementation. Exact closure may be full dimensional; a conventional compiler may already recover every useful structural saving. The next scientific action belongs to the independent supervisor reviewing current raw candidates, not an automatic additional toy experiment.

## What was actually executed

Frozen stdlib code ran through the already inspected coordinator runner. Each process had a 30-second external wall/CPU bound, denied numerical network access, scrubbed environment and writes restricted to probes/R. Serialization/exact basis reconstruction smoke passed before the substantive probe. The substantive process exited 0 in approximately 0.51 seconds according to the tool result. No neural learner, model training, paid route or downloaded code was executed.

1. For the task loss `0.5*((X B)[0,2]-1)^2` at B=0, with X=E12, a generic dense-gradient coordinate choice selected E23. Nine dense gradient entries were inspected and counted. This is classical gradient-directed birth, not neural discovery of a law.
2. The initial span{E23} could not represent the transported edit X E23=E13. It predicted zero output derivative under a naive orthogonal projection, whereas the true derivative was 1. Closure added E13 (dimension 1 -> 2; eight generator/edit matrix products).
3. One full gradient step B=E23 reduced the deliberately simple task loss from 1/2 to 0. This is a worked update, not evidence of an acquisition advantage. Forward algebra dimension grew from 4 to 6; edit dimension remained 2; compilation produced 60 table entries.
4. Compiled coefficient-space paired execution matched a dense forward-AD path exactly on all 1,093 words of length <=6 over three operators; 56 had nonzero derivatives. The two implementations share the inspected matrix arithmetic primitive, so this is a cross-check of the transport/table implementation, not a fully independent arithmetic verifier. Exact rational arithmetic avoided tolerance or finite-difference ambiguity.
5. Adding E31 made both execution and transported credit spaces dimension 9, the full 3x3 matrix space. This negative result is retained: compact exact closure can disappear when new interactions become useful.

The probe provides no resource-speed advantage claim. It includes the exact dense baseline and a failing fixed-credit-carrier control. Its small handcrafted operator context is an explanatory construction; it does not show autonomous neural acquisition, broad task transfer or causal evolvability.
