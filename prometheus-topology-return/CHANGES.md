# 本次改变

| 项目 | 新规则 |
|---|---|
| 主攻方向 | TOPOLOGY，human-only 变更；不能靠旧授权、review 或恢复日志自动替换 |
| 其他方向 | Online 保持 USER-PARK；Persistent State 安全保存后暂停独立投入 |
| 核心假说 | 拓扑保护在有用持续适应/新操作获取中的保持—学习—成本作用，明确为未验证 |
| 检验设计 | 先查是否直接触及核心主张；记录 DIRECT/PARTIAL/OUT_OF_SCOPE |
| 对照解释 | 分清独立现有方法、同机制重实现、消融和纯数字输出替代；保留强对手 |
| 审查者 | 保留事实否定和版本停止权；没有主线替换权；改为建设性里程碑审查 |
| 发展窗口 | 允许未知机制获得推导与诊断空间，不以预先胜过基线为入场条件 |
| 实验目标 | 有用改变、旧能力保持、相关总成本一起测；不重复微小更新/更多置换演示 |
| 中止 | 安全/资源/技术阻塞仍可停止；没有有信息价值的行动则 checkpoint，由人类决定战略 |
| 历史 | 不追改旧任务目标，不撤销已成立反例，不宣布未测优势为已确认 |

## 来源边界

Research review 011 明确只授权一次有限获取—更新—保持实验。Review012 识别了其任务只读取离散置换的限制，并明确把后续获取/保持价值留作 OPEN。Review013 对具体路径/覆盖版本给出了限定否定。用户本次授权改变下一阶段的优先级与审查制度；它不是对那些反例和数学结论的撤销，也不是此前长期优势已经成立的证明。
